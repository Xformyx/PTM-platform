# 과학적 검토와 staging 검증 기록

파일 이름은 COLLAB-REVIEW-001-short-title.md 형식을 사용한다. 기존 번호를 확인한다.
A의 ChatGPT Work에서 PI와 Scientific Reviewer의 의견을 나누어 기록하며, AI 검토를 독립적인 사람의 검토나 최종 승인으로 표기하지 않는다.

## 리뷰 양식

- 리뷰 ID / 날짜 / 작성자·역할:
- 연구 / TASK / PR:
- 검토 대상 commit·문서 버전:
- 검토 범위 / 미검토 범위:
- PI 관점: 목표·우선순위·범위 적합성:
- Scientific Reviewer 관점:
  - 근거와 주장 일치 / 관찰·추론·가설 구분:
  - 반증·대안 설명 / 대조군 / 데이터 누출:
  - 사전등록·동결 기준 / 다중 비교·불확실성:
  - 한계·과장·재현성:
- staging 검증:
  - 실행자·일시 / Mac Studio 환경:
  - commit / 데이터 버전·해시 / 설정·seed:
  - 재현 절차:
  - 기대 결과 / 관찰 결과:
  - 로그·산출물 위치:
  - 성공·실패·미실행 / 한계:
- 판정: accept / changes_requested / blocked
- 수정 요청과 해결 근거:
- 사용자 A의 최종 수용 여부·날짜·GitHub 링크:
- 후속 TASK / DECISION / STATUS 갱신:

검토 판정과 사용자 A의 수용을 별도 기록한다. 검증을 실행하지 않았다면 미실행으로 명시한다.
구현 성공은 연구 가설 지지를 뜻하지 않으며, 실패·미평가 결과도 원문과 함께 보존한다.
