# C3 사전등록 v1 — 비교가능성 제약 표현 학습

**상태: 동결 (2026-08-22).** §12의 동결 전 실측 4건 완료(§12.6). §13의 5개 항목 확정.
임계는 전부 **무제약 기저 대비 상대값**으로 선언되었고, 제약 적용 결과는 아직 산출되지 않았다.

**대상 설계:** `docs/integrated_research_design_v2.md` §7 (C3), §7.4 실험 E9–E12
**상위 문서:** `docs/ptm_representation_learning_contract_v1.md` §12.3 (A3의 재배치)
**작성:** 2026-08-22
**선행:** `c1_prereg_v1.md`(동결 2026-08-22), `c2_prereg_v1.md`(동결 2026-08-21)

## 0. 이 문서가 존재하는 이유

C1과 C2에서 배운 것이 이 문서의 형태를 정했다.

```text
C1 의 교훈  판정 규칙을 τ 계산 전에 동결한 덕에, 검정력 미달이 "평가 불가"로 남고
           "실패"로 오기록되지 않았다.  →  §12 를 §6 구현보다 앞에 둔다

C2 의 교훈  gate 의 선형 프로브는 **누출을 없애지 않고 비선형으로 옮기기만 해도** 통과한다.
           latent_dim 을 16 → 8 로 줄이면 induced R² 가 0.46 → 0.07 로 떨어지지만
           kNN 회수는 0.62 로 남았다.  →  §5 자명한 성공 차단을 **판정의 일부**로 둔다
```

C3에는 C2보다 더 노골적인 자명한 성공 경로가 있다. **모든 점을 각자의 군집에 두면
false-merge rate는 정확히 0이 된다.** 이 경로를 막지 않은 판정 규칙은 판정이 아니다.
§5가 이 문서에서 가장 중요한 절이다.

## 1. 판정 대상과 계산 경로

### 1.1 무엇을 주장하려는가

```text
주장  비교가능성 관계 O 를 학습 목적함수의 제약으로 넣으면, 데이터가 뒷받침할 수 없는
      쌍의 병합(false merge)이 줄어들고, 그 대가로 군집 구조의 정보량을 잃지 않는다

금지  "제약이 kinase 예측을 개선한다"
금지  "제약이 표현 품질을 높인다"        ← false merge 감소는 품질의 한 축일 뿐이다
금지  "비교 불가 쌍은 서로 다르다"       ← 비교 불가는 **증거 부재**이며 차이의 증거가 아니다
```

세 번째 금지가 C3의 해석 한계의 핵심이다. `O_ij = 0`은 "i와 j가 다르다"가 아니라
**"i와 j의 유사성을 판단할 공유 관측이 부족하다"**는 뜻이다. 따라서 제약의 목표는
"비교 불가 쌍을 멀리 두는 것"이 아니라 **"비교 불가 쌍에 대해 유사성을 주장하지 않는 것"**이다.
이 구별이 손실 설계(§6)와 지표 설계(§4)를 모두 결정한다.

### 1.2 계산 경로 (구현 전이므로 예정 경로)

```text
ptm_shared/representation/comparability.py          ← 신규. O 구성과 지표
  comparability_matrix(observed, t_min)             → bool[n, n]
  false_merge_rate(labels, comparability)           → §4.1
  merge_support(labels, comparability)              → §5.2

ptm_shared/representation/encoder.py                ← §6 제약 항 추가
ptm_shared/representation/benchmark.py              ← E10/E11 지표 병기
```

## 2. O 의 정의

### 2.1 관계

```text
O_ij = 1  ⟺  |{ t : observed_i(t) ∧ observed_j(t) }| ≥ T_min

T_min primary   = 4        (docs/integrated_research_design_v2.md §7.4 E12 에서 선언)
T_min 민감도    = {3, 5}   (sensitivity 전용. primary 승격 금지)
```

`observed`는 L3 다시점 입력(`MultiViewTemporalInput.target.observed`)의 마스크를 그대로 쓴다.
**새 결측 정의를 도입하지 않는다.** 이유는 §3.1.

`O`는 대칭이고 반사적이다(`O_ii = 1`, 자기 쌍은 지표에서 제외한다). `O`는 **추이적이 아니다** —
i–j 비교 가능, j–k 비교 가능이어도 i–k는 비교 불가일 수 있다. 이 비추이성이 §6에서 제약을
"동치류 분할"로 구현할 수 없는 이유다.

### 2.2 모집단

```text
확정  C3_POPULATION_V1 = c2_prereg_v1.md §1.1 과 동일

  단위                        form  (key_level = "form")
  minimum_observed_timepoints 3
  eligible_subset()           적용
  코호트                      HIRc-B (Order 52), T = 6
```

**C2와 같은 모집단을 쓰는 이유는 E11(C2 × C3)이 그것을 요구하기 때문이다.** 두 기여가 상호
대체적인지 상보적인지 보려면 같은 점 집합 위에서 비교해야 한다. 단위를 다르게 잡으면 E11의
4조합 비교가 성립하지 않는다.

site 단위는 sensitivity로만 본다. C1에서 site 단위를 쓴 것은 NNLS 입력이 site 단위였기 때문이며
(§`c1_prereg_v1.md` §2.1.2), C3에는 그 제약이 없다.

## 3. 정렬 확인 — 동결 전 필수

### 3.1 replicate 계층이 표현 입력에 없다 (A7)

`integrated_research_design_v2.md` §7.3은 **`replicate ≥ 2` 계층만 판정 가능**하다고 선언했고
(`n_eff` = 432 대 125), 이 값은 Core A/B 트랙에서 **원 `report.pr_matrix.tsv`의 run 수준**에서
산출되었다. HIRc-B는 시점당 3 run(`_01`, `_02`, `_03`)이다.

**그러나 표현 학습 입력에는 run 수준 정보가 없다.** `ptm_vector_data_normalized_phospho.tsv`의
시점 컬럼은 `{1,5,15,30,60,180}min_Mean_PTM_Relative` 즉 **이미 replicate 평균**이며, 시점별
replicate 수를 복원할 컬럼이 없다(`Occupancy_N`은 occupancy 계산의 n 이고 시점별이 아니다).

```text
결과  §7.3 이 "유일하게 판정 가능"하다고 선언한 계층을 표현 입력만으로는 구성할 수 없다
```

이것은 C1 §2.1의 정렬 문제와 같은 종류다. 세 갈래가 있다.

```text
(a) 원 matrix 에서 시점별 replicate 수를 세어 form 키로 올린 뒤 표현 입력에 결합
    → §7.3 의 계층과 n_eff 를 그대로 쓸 수 있다. 결합 손실률을 실측해야 한다 (§12.1)

(b) replicate 계층을 포기하고 O 를 표현 입력의 observed 마스크만으로 정의
    → 구현은 단순하나 §7.3 의 "replicate ≥ 1 계층 사용 금지"(n_eff = 125, 검정력 미달)를
      위반한다. 즉 판정 자체가 불가능하다

(c) 계층을 포기하고 검정력 재산정
    → n_eff 를 이 모집단에서 새로 측정해야 한다 (§12.3)
```

**(a)를 우선 시도하고, 결합 손실이 크면 (c)로 간다. (b)는 금지한다** — 검정력 미달 계층으로
판정하는 것은 사전등록 위반이다. 판단 기준은 §12.1의 실측이며, 그 값을 보기 전에 여기서
정한다: **form 키 결합률이 0.95 미만이면 (a)를 버린다.** 결합에서 탈락한 form 이 저관측 쪽에
쏠려 있으면(§7.2의 집중 구조가 바로 그 쪽이다) 탈락이 곧 신호의 제거이기 때문이다.

```text
확정 (2026-08-22, §12.1 실측 후)  경로 (a). 결합률 = 1.0000 (2,744 / 2,744, 탈락 0)

  판정 계층  replicate ≥ 2   (§7.3 이 유일하게 판정 가능하다고 선언한 계층)
  O 의 마스크  rep2_mask = (run 수준 replicate ≥ 2)  AND  (표현 입력 observed)
```

논리곱을 취하는 이유: run 수준에 값이 있어도 vector 단계에서 탈락한 항목을 관측으로
되살리지 않는다. 표현이 보지 못한 값으로 비교가능성을 주장할 수 없다.

### 3.2 O 를 만드는 마스크와 gate 를 만드는 마스크의 관계 (A8)

C2의 gate는 **induced masking** 후의 표현을 본다(`with_additional_target_masking`). 따라서
E10/E11에서 O 제약과 gate를 함께 볼 때 **O를 어느 마스크에서 만드는지**를 정해야 한다.

```text
확정  C3_MASK_SOURCE_V1 = 원본 observed 마스크

  O 는 induced masking 전의 관측 구조에서 만든다.
  induced mask 는 gate 지표 산출에만 쓰인다.
```

**이유.** O를 induced 마스크 후에 만들면 O가 seed마다 달라지고, 제약 자체가 인공 마스킹의
함수가 된다. 그러면 "제약이 false merge를 줄였다"와 "제약이 인공 마스크에 적응했다"를 구별할
수 없다. 원본 마스크에서 만든 O는 seed와 무관하므로 이 혼동이 생기지 않는다.

**대가를 기록한다.** induced masking 후에는 실제 공유 관측이 O가 말하는 것보다 적다. 즉
E10/E11에서 보는 false merge는 **하한**이다. 이 사실을 결과에 병기한다.

### 3.3 군집 정의 (A9)

```text
확정  C3_CLUSTER_V1 = benchmark.cluster_representation 그대로

  average linkage, cosine distance, distance_threshold = 0.30,
  minimum_cluster_size = 2, label 0 = 미배정
```

이 값들은 `layers.GATE_PROBE_PARAMETERS`에 동결되어 있다(`integrated_research_design_v2.md`
§8.2.1). C3이 새로 정하지 않고 **인용한다.** 군집 정의를 C3에서 바꾸면 C2의 retention ARI와
비교할 수 없고 E11이 무의미해진다.

`label 0`(미배정) 점들은 **서로 같은 군집이 아니다.** 지표 계산에서 0–0 쌍은 병합으로 세지
않는다. 이 규약을 어기면 미배정 점을 늘리는 것만으로 false merge가 폭증해 보인다.

## 4. false-merge 의 정의

`integrated_research_design_v2.md` §7.3은 "pair 수준 false-merge rate"라고만 적었다. 두 가지
자연스러운 정의가 있고 **성질이 다르다.**

### 4.1 두 정의

```text
FM_precision  = |{ (i,j) : 같은 군집 ∧ O_ij = 0 }| / |{ (i,j) : 같은 군집 }|
                "병합된 쌍 중 근거 없는 쌍의 비율"

FM_exposure   = |{ (i,j) : 같은 군집 ∧ O_ij = 0 }| / |{ (i,j) : O_ij = 0 }|
                "근거 없는 쌍 중 병합된 비율"
```

```text
확정  C3_PRIMARY_METRIC_V1 = FM_precision

  primary   FM_precision
  secondary FM_exposure  (병기 필수, 판정 아님)
```

**FM_precision을 primary로 택한 이유.** 분모가 "표현이 실제로 주장한 것"이다. C3의 주장은
"근거 없는 유사성 주장을 하지 않는다"이므로, 주장의 집합을 분모로 두는 것이 주장과 지표를
일치시킨다. FM_exposure의 분모(비교 불가 쌍 전체)는 §7.2에서 전역 2.51%/9.07%로 작고 저관측
feature에 집중되어 있어, 소수 feature의 거동이 지표를 지배한다.

**그러나 FM_precision 단독은 자명하게 낮출 수 있다.** 군집을 잘게 쪼개면 분모가 줄면서 분자가
더 빨리 줄기 때문이다. 극단에서 모든 군집이 크기 1이면 분모가 0이 되어 정의되지 않는다.
이것이 §5가 필요한 이유다. **FM_precision과 §5의 동반 지표는 함께 판정되며 분리할 수 없다.**

### 4.2 정의되지 않는 경우

```text
같은 군집 쌍이 0 개    → FM_precision 미정의. **자동 실패**로 처리한다 (§5.1 위반이기도 하다)
O_ij = 0 쌍이 0 개     → FM_exposure 미정의. FM_precision = 0 이고 C3 은 이 코호트에서 개선
                         여지가 없다. 이 경우는 §12.2 에서 사전에 확인한다
```

두 번째가 실제 위험이다. **기저 false merge가 이미 0에 가까우면 C3은 개선할 대상이 없다.**
§12.2가 이것을 동결 전에 확인한다. 결과를 본 뒤 지표를 갈아타지 않기 위해서다.

## 5. 자명한 성공 차단 — 이 문서의 핵심

### 5.1 왜 필요한가

```text
군집을 모두 크기 1 로 만들면              FM_precision 미정의 (병합 쌍 0)
군집을 극단적으로 잘게 쪼개면            FM_precision → 0
표현을 무작위로 만들면                    비교 불가 쌍이 특정 군집에 모이지 않아 FM 이 내려간다
```

세 경로 모두 **표현을 나쁘게 만들어서 지표를 좋게 만든다.** C2의 E8이 정확히 이 구조를
드러냈다 — latent_dim을 줄이면 gate를 통과하지만 표현이 좋아진 것이 아니었다. C3에서는 그
경로가 더 짧다.

### 5.2 동반 지표

```text
확정  C3_TRIVIALITY_GUARD_V1 (2026-08-22, §12.4 실측 후) — FM_precision 과 **동시에** 판정

  G1a 구조 보존      ARI(제약 군집, 무제약 군집)  on 비교 가능 쌍만   ≥ 0.0237
  G1b 식별성 비퇴행  제약 표현의 seed 간 ARI      on 비교 가능 쌍만   ≥ 0.0237
  G2  제거 표적성    Δfalse_merges / Δmerged_pairs                    ≥ 0.50
  G3  예측력         공정 프로브 ΔR²                                  ≥ 0.01355
```

**G1a를 비교 가능 쌍에서만 재는 이유.** 제약의 목적이 비교 불가 쌍의 처리를 바꾸는 것이므로,
그 쌍에서 군집이 달라지는 것은 **의도된 변화**다. 전체 쌍에서 ARI를 재면 의도된 변화가
"구조 파괴"로 잡힌다.

**G1a 임계 0.0237의 근거와 그 약점.** §12.4에서 arm D의 **제약 없이 인코더 seed만 바꾼**
두 적합 사이의 비교 가능 쌍 ARI가 0.0237–0.0373이었다. 0.0237은 그 하한이다. 즉 임계는
"제약이 seed를 바꾸는 것보다 구조를 더 망가뜨리지 않았다"를 뜻한다.

```text
이 임계는 약한 기준이다. 숨기지 않고 적는다.

  같은 seed 의 제약 대 무제약은 초기화를 공유하므로, 제약이 아무 일도 하지 않아도
  seed 간 값보다 높게 나온다.  따라서 G1a 통과는 "구조가 보존되었다"의 강한 증거가 아니다.

  그럼에도 절대 임계를 쓸 수 없다 — 무제약 표현 자체가 ARI 0.02–0.04 수준에서만
  재현되므로, 예컨대 0.50 같은 임계는 무제약 기준선도 통과하지 못한다.
```

**그래서 G1b를 추가한다.** 제약을 걸고 seed만 바꿔 두 번 적합해, 그 사이의 ARI가 무제약의
seed 간 ARI 하한을 밑돌지 않아야 한다. 이것이 **제약이 표현을 더 식별 불가하게 만들지
않았는가**를 직접 본다. G1a가 약한 만큼 G1b가 필요하다.

**G2가 자명한 성공을 직접 막는다.** 초안은 "병합 쌍 수 비율"이었으나, 기저를 실측한 뒤
**제거의 표적성**으로 바꿨다. 비율 하한은 임의값이 되는데 표적성은 그렇지 않다.

```text
무작위로 병합을 제거하면  removal_precision ≈ 기저 FM_precision = 0.1042  (arm D, §12.2)
G2 = 0.50 은 무작위의 약 4.8 배를 요구한다.
제거된 병합의 절반 이상이 false merge 여야 한다는 뜻이다.

병합 쌍이 줄지 않았는데 FM 이 개선되면 구조를 축소하지 않고 개선한 것이므로 통과 처리한다
(`comparability.removal_precision` 의 `no_shrinkage`).
```

**G3은 새 임계를 만들지 않는다.** `c2_prereg_v1.md` §7.2의 동결 임계(ΔR² ≥ 0.01355)를 인용한다.

### 5.3 판정 결합

```text
확정  C3 성공 =  FM_precision 유의 개선 (§7)
              ∧  G1a ≥ 0.0237  ∧  G1b ≥ 0.0237
              ∧  G2  ≥ 0.50
              ∧  G3  ≥ 0.01355   (c2_prereg_v1.md §7.2 인용)

  OR 성공 금지.  다섯 조건의 논리곱이며 어느 하나로 성공을 주장하지 않는다
```

C1 §6에서 OR 성공을 금지한 것과 같은 이유다. 조건이 4개일 때 OR을 허용하면 다중성 보정 없는
4회 검정이 된다.

## 6. 제약 기제

### 6.1 무엇을 제약하는가

§1.1에서 정한 대로, 목표는 비교 불가 쌍을 **멀리 두는 것이 아니라** 그 쌍에 대해 유사성을
주장하지 않는 것이다. 세 후보가 있다.

```text
M1  마스킹형   이웃 계산·대조 손실에서 O_ij = 0 쌍을 **제외**한다
               → "주장하지 않는다"의 직역. 손실에 항을 더하지 않고 항을 뺀다

M2  벌점형     O_ij = 0 이면서 임베딩 거리가 가까운 쌍에 벌점을 준다
               → 비교 불가 쌍을 능동적으로 밀어낸다. §1.1 의 세 번째 금지에 저촉될 위험

M3  구조형     O 를 존중하는 그래프 라플라시안 정칙화
               → M1 의 연속 완화. 비추이성(§2.1) 때문에 분할로 환원되지 않는다
```

```text
확정  C3_MECHANISM_V1 = M1 (primary)

  M2 는 사전등록된 대안 경로로만 둔다.  M1 이 §5.3 을 통과하지 못하고
  **그 원인이 "제약이 너무 약하다"로 진단될 때만** 실행하며, 그 경우 M2 결과는 탐색적이다
```

**M1을 primary로 택한 이유가 §1.1의 해석 한계와 직결된다.** M2는 "비교 불가 = 서로 다르다"를
목적함수에 새겨 넣는다. 그것은 증거 부재를 차이의 증거로 바꾸는 것이고, 논문에서 방어할 수
없다. M1은 증거가 없는 쌍에 대해 **아무 말도 하지 않는다.**

M2를 완전히 버리지 않는 이유는, M1이 효과가 없을 때 "제약이 약해서"인지 "제약이 무의미해서"인지
구별할 필요가 있기 때문이다. 그 구별은 탐색적이며 C3의 채택을 바꾸지 않는다.

### 6.2 M1 이 어디에 들어가는가

현 인코더의 손실에는 쌍 항이 없다(재구성 + 정칙화 + §C2 adversary). 군집은 **학습 후**
임베딩에 average linkage를 적용해 만든다. 따라서 M1의 적용점이 두 곳으로 갈린다.

```text
M1-loss   대조 손실 항을 **새로 추가**하고 그 항에서 O_ij = 0 쌍을 제외한다
          → 새 손실 항의 도입 자체가 교란이다. 제약의 효과와 대조 손실의 효과가 섞인다

M1-metric 군집·이웃 계산에서 O_ij = 0 쌍을 제외한다 (학습은 그대로)
          → 사후 처리에 가깝다. §7.3 이 "guard 에서 제약으로" 옮기려던 것과 반대 방향
```

```text
확정  C3_APPLICATION_POINT_V1 = M1-loss, 3-기준선 설계 (2026-08-22, §12 실측 후)

  기준선 0  대조 손실 없음        = 현행 arm D
  기준선 1  무제약 대조 손실       = 대조 항은 있으나 O_ij = 0 쌍도 포함
  처리      제약 대조 손실         = 대조 항에서 O_ij = 0 쌍 제외

  primary 대조 = 처리 대 기준선 1.   기준선 0 은 대조 항 자체의 효과를 분리하기 위해 병기
```

M1-loss는 §7.3의 의도("사전 제약")에 맞지만 새 손실 항이 교란을 만든다. M1-metric은 교란이
없지만 §7.3이 벗어나려던 사후 guard와 구별이 흐리다. 3-기준선 설계가 M1-loss의 교란을
제거하므로 M1-loss를 택했다.

### 6.3 대조 손실의 함수형 — 2026-08-22 선언 (구현 착수 전)

§6.2는 기제 족만 정했고 **함수형을 정하지 않았다.** 그것은 이 문서의 공백이었다. 구현하기
전에 여기서 선언한다. 순서를 뒤집지 않는다
(`.cursor/rules/research-code-provenance.mdc` §2).

```text
확정  C3_CONTRASTIVE_V1 — InfoNCE, 코사인 유사도

  u_i    = z_i / ‖z_i‖                      임베딩 행 정규화
  s_ij   = (u_i · u_j) / T                  T = 온도
  L      = −(1/n) Σ_i log( Σ_{j∈P_i} e^{s_ij} / Σ_{j∈N_i} e^{s_ij} )

  P_i    양성 = 관측 거리 d_obs 기준 i 의 최근접 k 개  (자기 제외)
  N_i    후보 = j ≠ i 전체                   (P_i ⊆ N_i)

  d_obs(i,j) = sqrt( 공유 관측 시점에서의 (x_it − x_jt)² 평균 )
               공유 시점이 0 이면 +∞ (양성이 될 수 없다)
```

**양성을 임베딩이 아니라 관측 데이터에서 정하는 것이 핵심이다.** 임베딩에서 정하면 손실이
자기 자신을 강화하는 되먹임이 되어 아무것도 학습하지 않는다.

```text
제약의 작용점 (§6.1 M1 = 마스킹형)

  무제약 (기준선 1)   P_i, N_i 는 모든 j ≠ i 에서 만든다
  제약   (처리)       P_i, N_i 에서 O_ij = 0 인 j 를 **뺀다**

  즉 제약은 항을 더하지 않고 항을 뺀다.  비교 불가 쌍에 대해 손실이 아무 방향도 주지 않는다
```

`d_obs`에 행 표준화를 적용하지 않는다. 표준화 통계량이 관측 마스크에 의존하므로, 표준화하면
거리 자체가 coverage 의 함수가 되고 C2가 겨냥한 문제를 대조 항에 다시 들여온다.

#### 6.3.1 초모수 — 결과 열람 전 확정

```text
T (온도)          0.5        InfoNCE 관례값. C3 이 새로 탐색하지 않는다
k (양성 수)        10        c2_prereg_v1.md §1.1 의 `neighbors` = 10 을 인용
λ (대조 항 가중)   1.0        primary.  민감도 {0.3, 3.0} (sensitivity 전용)
epochs            150        기존 arm D 설정 불변
인코더 seed        {0, 1}     G1b 가 조건별 2회 적합을 요구한다 (§5.2)
```

**λ 가 판정 대상이 아니라는 점을 분명히 한다.** 기준선 1과 처리가 **같은 λ**를 쓰므로 λ는
"대조 항의 세기"이고 C3이 검정하는 것은 "그 항에서 비교 불가 쌍을 뺀 효과"다. 따라서 λ를
바꿔 유리한 값을 찾는 것은 C3의 판정과 무관하며, 그렇게 해도 primary 대조는 변하지 않는다.
민감도 두 값은 **결론이 λ에 뒤집히는지**만 본다.

#### 6.3.2 자명성 검사 — 대조 항이 실제로 작동했는가

비교가 공허해지는 경로가 두 개 있고, 둘 다 **판정 전에** 확인한다.

```text
S1  대조 항이 임베딩을 바꾸지 않았다
      기준선 1 과 기준선 0 의 비교 가능 쌍 ARI 가 seed 잡음 범위(0.0237–0.0373) 안이면
      λ = 1.0 은 너무 약하다.  → §6.3.1 민감도 λ = 3.0 으로 재실행하고 그 사실을 기록한다

S2  제약이 손실을 비워버렸다
      제약으로 P_i 가 빈 행의 비율이 0.20 을 넘으면, 처리는 "제약"이 아니라 **데이터 삭제**다
      → E9 를 판정에 쓰지 않고 T_min 을 낮춘 sensitivity 로만 보고한다
```

**S2 의 임계 0.20 은 실측 착수 전 여기서 선언한다.** 근거는 §12.3이다 — `rep≥2`·`T_min=4`에서
비교 불가 쌍이 전역 20.2%이므로, 양성 후보가 그보다 크게 더 많이 사라지면 손실이 겨냥하는
구조가 남지 않는다. 이 값을 실행 후에 정하면 "제약이 작동했다"를 사후에 정의하게 된다.

**primary 대조를 기준선 1로 두는 것이 이 결정의 핵심이다.** 처리를 기준선 0과 비교하면
"대조 손실을 추가한 효과"와 "그 항에서 비교 불가 쌍을 뺀 효과"가 섞인다. C3이 주장하는 것은
후자뿐이다. 전자는 C3의 기여가 아니다.

**대가.** E9의 적합 횟수가 3배가 된다(추가로 §5.2 G1b가 seed당 2회를 요구하므로 실제로는
더 늘어난다). 이 비용을 받아들인다 — 교란된 primary 대조는 비용을 아껴서 얻을 것이 없다.

## 7. 불확실성과 검정력

### 7.1 클러스터 부트스트랩

```text
확정  C3_BOOTSTRAP_V1

  단위        feature (form)
  방법        feature 를 복원 추출하고, 추출된 feature 가 종단인 쌍으로 지표를 재계산
  반복        2000
  seed        20260822
  구간        percentile 95%
```

쌍은 독립이 아니다. 한 feature가 수천 쌍의 종단이므로 쌍 단위 부트스트랩은 구간을 과소추정한다.
`integrated_research_design_v2.md` §7.3이 feature-clustered를 지정한 이유다.

### 7.2 짝지어진 비교

무제약과 제약은 **같은 점 집합**에서 계산되므로 짝지어진 설계다.

```text
확정  primary 검정 = 짝지어진 부트스트랩 차이의 95% 구간이 0 을 포함하지 않음
      방향        = FM_precision(제약) < FM_precision(무제약)
      보조        = 쌍별 불일치의 McNemar 형 요약 (기술 통계, 판정 아님)
```

단측 방향을 사전에 고정한다. 제약이 false merge를 **늘리는** 결과는 개선이 아니라 반증이다.

### 7.3 검정력

§7.3의 산정(α=.05, power=.80, ψ=0.75, 불일치율 5%→578 / 10%→289 / 20%→145 쌍, `n_eff` 432)은
**Core A/B 트랙의 모집단에서 나온 값이다.** 이 모집단에서 다시 재야 한다(§12.3).

```text
금지  n_eff 를 재측정하지 않고 432 를 인용하는 것
금지  검정력 미달로 나왔을 때 계층을 replicate ≥ 1 로 완화하는 것 (§3.1 (b))
```

C1에서 정확히 이 지점이 문제가 되었다. 세 확장 수준 전부가 검정력 미달이었고, 그것을
**τ 계산 전에** 발견해서 "평가 불가"로 남길 수 있었다.

### 7.4 검정력 판정 (2026-08-22, §12.3 실측 후)

```text
판정 계층 rep≥2, T_min = 4 (primary)

  n_eff                       995.2      (§7.3 의 432 가 아니다. 이 모집단의 값)
  필요 표본 5% 불일치          578        →  충족
  달성 가능 불일치의 상한       8.60%     =  FM_exposure(arm D, rep≥2, T_min=4)

확정  E9 primary 는 검정력을 충족한다.  n_eff 995.2 ≥ 578 이고 상한 8.60% > 5% 다
```

**"달성 가능 불일치의 상한"을 함께 보는 이유.** `n_eff`만 크면 검정력이 있다는 말은 틀렸다.
제약이 완벽하게 작동해도 뒤집을 수 있는 쌍은 현재 잘못 병합된 쌍뿐이므로, 불일치율은
`FM_exposure`를 넘을 수 없다. 검정 가능한 최소 불일치율이 그 상한보다 크면 **검정력이 있어도
검출 대상이 없다.** 두 수를 함께 보지 않으면 이 함정을 놓친다.

rep≥1 계층에서는 이 함정이 실제로 발동했음을 기록한다 — `n_eff` = 304.4로 10% 불일치만
검출 가능한데(289) 상한은 8.60%보다 작은 6.54%였다. §7.3이 rep≥1을 금지한 것은 결과적으로
옳았고, 그 이유는 §7.3이 적은 것보다 하나 더 있다.

`T_min` 민감도 두 수준도 충족한다(rep≥2에서 `n_eff` = 626.6 / 1381.0). 다만 sensitivity 이므로
primary 로 승격하지 않는다.

### 11.1 기존 표현 학습 수치가 계산된 계층 (2026-08-22 발견)

§12.1에서 표현 입력의 `observed` 마스크가 run 수준 `replicate ≥ 1`과 0.012%만 다름을 확인했다.

```text
결과  지금까지 산출된 모든 표현 학습 지표(C0 gate, 공정 프로브, C2 E4–E8)는
      사실상 replicate ≥ 1 계층에서 계산되어 있다

      integrated_research_design_v2.md §7.3 은 그 계층을 **C3 판정에 대해** 금지했다
      (n_eff 검정력 미달).  그 금지는 pair 수준 false-merge 검정에 대한 것이며
      site 수준 예측 지표를 무효화하지 않는다
```

**두 사실을 구별해서 적는다.** §7.3의 금지는 "비교 불가 쌍의 pair 검정에서 `rep≥1`의

수치가 무효가 되지는 않는다. **그러나 그 수치들은 "replicate 1개로 관측된 값도 포함한
데이터"에서 나온 것이며, 논문에서 그렇게 기술해야 한다.** 지금까지 그 사실이 어디에도
적혀 있지 않았다.

## 12. 동결 전 실측 — 이것이 끝나기 전에 구현하지 않는다

### 12.1 A7 — replicate 계층의 결합 가능성

원 `report.pr_matrix.tsv`에서 시점별 replicate 수를 세어 form 키로 올린 뒤, 표현 입력의 form
키와 결합한다. **측정할 값:** 결합률, 탈락 form 의 관측 시점 수 분포(저관측 쪽 편중 여부),
`replicate ≥ 2` 마스크와 표현 입력 `observed` 마스크의 불일치율.
**판단:** 결합률 < 0.95 → §3.1 (a) 폐기, (c) 로 이동.

### 12.2 기저 FM_precision — 개선 여지가 있는가

무제약 arm A·B·D·E 각각에 대해 FM_precision, FM_exposure, 병합 쌍 수, 군집 수를
T_min ∈ {3,4,5}에서 측정한다.
**판단:** 기저 FM_precision 이 0 에 가까우면 §9의 반증 조건 5가 발동한다.

### 12.3 n_eff 재측정

이 모집단에서 Kish 실효 cluster 수를 다시 계산하고 §7.3의 필요 표본과 대조한다.
**판단:** 미달이면 §9의 반증 조건 6.

### 12.4 병합 규모 기저 — G2 임계 산정 근거

무제약 군집의 병합 쌍 수, 군집 크기 분포, 미배정 비율을 측정한다.
**용도:** §5.2의 G2 임계를 이 값에 근거해 §13에서 확정한다. **기저를 모르는 상태에서 비율
임계를 정하면 임의값이 된다.**

### 12.5 §12 실측이 임계 산정 전이어야 하는 이유

(아래 §12.6이 실측 결과다.)

§12는 **기술 통계만** 측정한다. 판정 임계(G1, G2)는 §12 이후 §13에서 정한다. 이 순서는
`.cursor/rules/research-code-provenance.mdc` §3의 "결과 열람 후 확정 → 탐색적"에 저촉되지
않는다 — G1·G2가 대상으로 하는 양(제약 적용 후의 지표)은 §12에서 측정되지 않기 때문이다.
§12는 **무제약 기저**만 보고, 임계는 그 기저에 대한 상대값으로 선언된다.

```text
허용  "무제약 병합 쌍 수의 X% 이상을 유지해야 한다"  ← 기저 대비 상대 임계. 제약 결과 미열람
금지  "제약 적용 후 병합 쌍 수가 N 이상이어야 한다"  ← 제약 결과를 본 뒤 정하면 사후 선택
```

  인코더 seed 만 변경 (마스킹 없음) ARI = 0.0427 – 0.0675
  자기 대조 (건전성 검사)          ARI = 1.0
```

**데이터의 15%를 가리는 것이 인코더 seed 를 바꾸는 것보다 군집을 덜 흔든다.** 따라서
`missingness_validity` gate의 retention ARI 하위 조건을 arm D에 적용하면, 그것이 재는 것은
마스킹 강건성이 아니라 **군집의 seed 불안정**이다. C2가 adversary로 ARI 조건을 통과할 수
없었던 이유가 여기서 설명된다 — 그 조건은 coverage 와 무관한 양을 재고 있었다.

이 발견은 C3의 사전등록 사안이 아니라 **C2의 한계 기술 장에 속한다.**
`c2_prereg_v1.md` §13.2에 반영한다.

**공정 프로브는 이 문제를 겪지 않는다.** `fair_probe.DEFAULT_CONFIG` 의
`n_encoder_seeds = 5`이며 `compare_to_baseline`이 학습 arm의 seed를 fold별로 평균한다.
즉 **프로브는 설계상 인코더 seed를 평균하고 gate는 그렇지 않다.** C0의 D > B 결론이
기하 비식별성과 양립하는 이유다 — 프로브는 열공간(회전 불변)에만 의존하고, 열공간은
부분적으로 재현된다(0.18–0.20).

```

### 15.3 현행 arm D 대비로는 개선이 아니다

병기한 기준선 0(대조 항 없음 = 현행 arm D)의 FM_precision은 **0.10421**이다.

```text
기준선 0 (현행 arm D)      0.10421   ← 가장 낮다
처리     (제약 대조 손실)   0.11548
기준선 1 (무제약 대조 손실) 0.14436   ← 가장 높다
```

대조 항을 추가하는 것 자체가 FM_precision을 악화시키고(0.1042 → 0.1444), 제약은 그 악화의
약 70%를 회복하지만 기준선 0을 넘지 못한다. §6.2가 primary 대조를 "제약 대 무제약"으로
고정했으므로 §5.3 판정은 성립하지만, **"C3가 현행 표현을 개선한다"는 주장은 이 결과로
성립하지 않는다.** 성립하는 주장은 다음 하나다.

> 대조 손실을 쓰는 표현 학습에서, 비교가능성 관계를 손실에서 존중하면 근거 없는 병합이
> 줄어든다. 단, 관측된 개선은 대조 항 세기 λ에 의존하며 대조 항을 쓰지 않는 표현보다
> 낫다는 뜻은 아니다.

### 17.1 남는 것 — Chapter 4의 내용

```text

   2-arm 설계는 기준선 선택에 따라 "효과 없음" 또는 "성공" 중 하나만 보고했을 것이다 (§16.3)
   → 사전등록 설계에 대한 방법론적 기여

6  비교가능성 제약은 마스킹 하 군집 안정성을 C2 보다 크게 올린다 — **탐색적**
   retention ARI 0.035 → 0.126.  C2 가 8 λ 전체에서 넘지 못한 하위 조건이다 (최대 0.066)
   E10 은 판정 실험이 아니므로 primary 승격 영구 금지.  후속 연구 가설로만 기록한다

7  3·4 의 기전 — 여지 자체가 층 혼합의 산물이었다 — **탐색적**
   층 내 비교 불가 기저율과 나란히 재면 FM_precision 의 비가 어느 층에서도 1 을 넘지 않고
   (0.74–1.00), 전체의 0.52 는 기저율 0.042 인 큰 층과 1.0 에 가까운 작은 층의 혼합에서
   나온다.  비교 불가가 밀집한 층에서는 줄일 여지가 **구조적으로 없다**
   → λ 취약성(3)과 C2 와의 대립(4)이 같은 원인에서 나온다는 설명
   근거는 C2 의 E7 층화 진단이다 (`c2_prereg_v1.md` §9.2.3–§9.2.4)
```

**4번이 논문에서 가장 값이 있다.** C2와 C3는 각각 실패했지만, 둘이 **대립한다는 사실**은
어느 한쪽만 했으면 나오지 않는 결과다. "결측 구조를 표현에서 빼는 것"과 "결측 구조를
비교가능성으로 존중하는 것"이 같은 표현 안에서 양립하지 않는다는 것이 PTM 시계열 표현
학습의 구조적 제약으로 기술될 수 있다.
