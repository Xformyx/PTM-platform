## 0. 왜 지금 요청하는가

두 가지 시한이 겹쳤다.

1. **사전등록 동결이 임박했다.** 동결하면 통계 설계가 잠긴다. 잘못 설계된 검정을 동결하는 것은
   동결을 늦추는 것보다 나쁘다. 임계값 일부는 근거가 약하다(§1).
2. **선행 조사에서 C1의 신규성이 크게 약화되었다.** 학위논문 척추를 옮겨야 할 수 있고, 이 판단은
   측정으로 풀리지 않는다(§2).

이 문서는 두 질문만 담는다. 배경은 대상 문서에 있으므로 반복하지 않는다.

## 1. 질문 A — 사전등록의 통계 설계 (동결 전, 시한 있음)

### 1.1 문제 상황 요약

고정된 하류 추정기는 site별 NNLS다.

```text
site i:  minimize ||A_i a − y_i||₂  s.t. a ≥ 0
         y_i ∈ R^T (T = 3–9),  A_i ∈ R^{T×K_i} (K_i = 23–111)
```

실측 진단(6 오더 1,310 site): rank-1 설계 54.4%, `equal_weight_fallback` 46.2%,
구조적 미결정 94.4%, duplicate 열 61.5–100%, identifiable 1.1%.

τ는 상류 표현 섭동 `d_i`가 `A_i`의 열공간에 남는 에너지 비율이다.

```text
τ_act(i) = ||P_col(A_i[:, active_i]) d_i||² / ||d_i||²
```

### 1.2 검토를 요청하는 판정 규칙

**E1b (판별력 — τ가 방향 무관 지표를 넘는 정보를 담는가)**

```text
계층 한정: S-EVAL = rank(A_i) ≥ 2 ∧ cond 유한 ∧ fallback 아님
          (rank-1 에서 cond = ∞ 포화 → 전체 모집단 검정은 거짓 통과)

X = { log10(design_cond), log10(active_cond), active_sigma_min,
      max_column_coherence, design_rank, n_redundant }

R2_iso = X 각 성분의 등위회귀 예측을 비음수 최소제곱으로 결합한 모형의
         τ_act 설명 분산 비율 (5-fold CV, fold 는 유전자 블록 단위)
disc   = τ 하위 20% 이나 X 기반 예측 τ 는 상위 50% 인 site 비율

통과 = R2_iso < 0.80  ∧  disc ≥ 0.05
```

**E3 (held-out 예측 타당도)**

```text
블록 = 유전자.  sha256(gene + "c1-prereg-v1") 로 calibration 50% / held-out 50%
Δẑ  = ||ratio(y_i + d_i) − ratio(y_i)||₁
판정 = held-out 에서 high-τ / low-τ 군의 블록별 median Δẑ 차이
      블록 단위 순열검정 10,000회 양측, p < 0.05 ∧ |Cliff's delta| ≥ 0.20 ∧ 방향 일치
```

**검정력 기준**

| \|S-EVAL\| | 지위 |
|---|---|
| ≥ 195 | 확증 검정 (Spearman Fisher-z CI 반폭 ≤ 0.15) |
| 73–194 | 검정력 부족. 점추정·CI만 보고 |
| < 73 | 미평가 |

### 1.3 구체적으로 답을 원하는 것

**(A-1) 임계값의 허수.** `R2_iso < 0.80`과 `disc ≥ 0.05`는 근거가 약하다. 등위회귀를 쓴 것은 단조
관계를 모두 허용해 τ에 **불리**하게 만들려는 의도이고, `Cliff's delta ≥ 0.20`은 관행적 근거가 있다.
그러나 0.80과 0.05의 **수준 자체는 임의적이다.** 원칙 있는 대안이 있는가, 아니면 임의성을 인정하고
민감도 곡선(임계를 변화시킨 판정 변화)을 함께 보고하는 것이 정직한가.

**(A-2) `R2_iso`가 건전한 통계량인가.** 6개 예측자의 등위회귀 예측을 비음수 최소제곱으로 결합하는
구성은 과적합에 취약할 수 있다. 등위회귀는 단조 계단함수로 표본을 따라가므로 `n`이 작을 때 `R2_iso`가
**위로** 편향되어 C1이 부당하게 기각될 수 있다. CV가 이를 충분히 교정하는가, 아니면 더 단순한
비교(예: 부분 Spearman, 또는 단일 최량 예측자에 대한 증분)가 나은가.

**(A-3) `disc`의 정의.** "τ 하위 20% ∧ 예측 상위 50%"는 두 절단점에 의존한다. 절단점 없는
재순서화 측도(예: 두 순위의 불일치 통계량)가 더 방어 가능한가.

**(A-4) 블록 분할.** 유전자 단위 50/50이 적절한가. `S-EVAL`이 작을 가능성이 높은데(하한 ≈ 0),
50%를 calibration에 쓰는 것이 낭비인가. 교차적합(cross-fitting)으로 전량을 쓰되 사전등록을 유지하는
설계가 가능한가.

**(A-5) 다중성.** E1, E1b, E2, E3, E3b가 모두 C1의 판정에 관여한다. 다중 비교 보정이 필요한가,
아니면 각각이 서로 다른 명제를 검정하므로 불필요한가.

**(A-6) `S-DEAD` 처리.** `equal_weight_fallback` site(46.2%)는 NNLS 해가 전부 0이라 출력이 상수다.
`Δẑ ≡ 0`이므로 E3에서 제외했다. 제외가 옳은가, 아니면 이들을 포함해 "전달률 0"으로 다루는 것이
추정량을 왜곡하지 않으면서 더 정직한가.

## 2. 질문 B — 학위논문 척추 재배치 (측정으로 풀리지 않음)

### 2.1 선행 조사 결과

C1의 두 축이 모두 선행 연구로 확인되었다.

```text
τ_col = dᵀ R_data d / dᵀ d,  R_data = A A⁺
      = 선형 역문제의 data resolution matrix 의 방향별 Rayleigh 몫
        (Backus–Gilbert 1968; Wiggins 1972; Jackson 1972)

"상류 표현 품질이 고정 하류 추정기로 전달되지 않을 수 있다"
      = objective function mismatch / metrics mismatch (Neural Comput. Appl. 2022)
        SSL 평가 프로토콜과 하류 성능의 괴리 (IJCV 2025 등)
        "Frozen but Not Always Accessible" (arXiv 2608.05329, 2026-08, genomic LM)
```

즉 **양도 현상도 신규가 아니다.**

### 2.2 잔여 기여

| 요소 | 잔여 |
|---|---|
| `τ_act` (활성집합 제한 resolution) | 2회 조사에서 직접 선행 연구 미발견. **작고, 미발견은 부재의 증명이 아니다** |
| prior 기반 dictionary의 rank 붕괴가 전달 실패의 기전이라는 실증 | 실재. 도메인 특수 |
| site 약 46%에서 추정기가 데이터의 함수조차 아니라는 감사 | 실재. 논쟁 불가능 |
| C0 — 다시점 마스킹의 대수적 누출과 그것을 잡은 잡음 대조 | 실재. 구현·실측 완료 |
| C2 (coverage 분리) / C3 (비교가능성 제약) | 실제 **방법** 기여. **둘 다 미구현** |

### 2.3 구체적으로 답을 원하는 것

**(B-1) 재배치 방향.** 현재 판단은 **C2+C3을 중심, C1을 진단 장, C0를 평가 기반**으로 옮기는 것이다.
이 구조가 CS 학위논문으로 성립하는가. 대안(C0 중심, 또는 도메인 감사 중심)이 더 나은가.

**(B-2) 위험 이동을 감수할 것인가.** 재배치하면 단일 실패점이 C1에서 **미구현인 C2/C3으로 이동**한다.
현재 증거가 있는 것(C0, C1의 도메인 실증)에서 증거가 없는 것으로 무게를 옮기는 셈이다. 이것이
합리적인 거래인가, 아니면 순서를 바꿔 C2/C3을 먼저 구현해 성공을 확인한 뒤 척추를 정해야 하는가.

**(B-3) `τ_act`에 무게를 걸 수 있는가.** 활성집합 제한 resolution 해석의 선행 연구를 더 조사할
가치가 있는가. 있다면 어느 문헌(제약 최적화 민감도, hyper-differential sensitivity analysis, 활성집합
섭동 이론)을 봐야 하는가. 없다면 이 증분을 포기하고 도메인 실증만 남기는 것이 정직한가.

**(B-4) 도메인 감사 결과의 위상.** "배포된 생물정보 파이프라인의 site 46%에서 보고되는 kinase 귀속이
데이터의 함수가 아니다"는 결과는 강하지만 방법 기여가 아니다. CS 학위논문에서 이런 감사 결과가
독립 장으로 받아들여지는가, 아니면 방법 기여의 동기 부여로만 쓰여야 하는가.
