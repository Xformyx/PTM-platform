# 연구 협업 현황

기준일: 2026-09-11. 범위: 협업 문서 도입 시점의 인계 상태.
이 표는 전체 연구나 staging의 최신 상태를 검증했다는 뜻이 아니다.

| 항목 | 현재 상태 | 다음 행동 | 담당 |
|---|---|---|---|
| 협업 역할·수동 인계 구조 | 사용자 요청으로 합의됨 | PROJECT_CONTEXT를 기준으로 운영 | A/B |
| 기존 연구 문서 | 설계·사전등록·원장 존재 확인 | 활성 연구와 기준 commit 확정 | A/B |
| 기존 개발 작업 | 루트 todo.md 존재 확인 | 현재 미완료 항목 중복 대조 | B, A 검토 |
| 신규 구현 TASK | 이 문서 도입으로 승인된 구현 없음 | TASK 작성 후 A 승인 | A |
| Mac Studio staging | 이번 작업에서 실행 상태 미확인 | 첫 승인 TASK에 검증 환경 명시 | TASK 담당 |
| 자동화/Orchestrator | 이번 범위에서 제외 | 별도 요청 전 보류 | A |

## 인계 기록 양식

- 갱신 일시·작성자:
- 기준 branch / commit:
- 연구 ID / TASK ID:
- 상태: proposed / approved / in_progress / review / blocked / done
- 변경 요약:
- 근거 링크(코드·결과·리뷰):
- 장애물·미확인 사항:
- 다음 행동·담당:
- A의 승인 또는 수용 기록:

done은 TASK 완료 기준, 필요한 staging 검증, 리뷰와 A의 수용 근거가 연결된 경우에만 사용한다.
코드 구현 완료와 과학적 가설 지지는 별도 기록한다. 상태가 바뀌면 TASK 원문을 먼저 갱신하고 이 요약과 [백로그](BACKLOG.md)를 맞춘다.
