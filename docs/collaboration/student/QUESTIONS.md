# 연구 질문 기록

신규 질문은 아래 양식을 복사하여 추가한다. 현재 실제 질문은 등록되지 않았다.
질문 ID는 COLLAB-Q-001부터 기존 번호를 확인하고 부여한다.

## 질문 양식

- ID / 제목 / 날짜:
- 작성자:
- 상태: open / investigating / answered / decision_needed / closed
- 관련 연구·TASK / 기준 commit:
- 질문:
- 이미 확인한 내용:
- 근거(문서 절·논문·데이터·결과 링크):
- 내 해석과 불확실성:
- 시도한 방법:
- 원하는 도움 / 제안하는 다음 행동:
- PI 답변:
- Scientific Reviewer 의견·반증:
- A의 결정과 근거 링크(필요한 경우):
- 연결된 BACKLOG / TASK / DECISION:
- 종료 사유·확인자·날짜:

답변이 구현 변경을 요구하면 TASK 승인 흐름으로 연결한다. answered는 구현 승인을 뜻하지 않는다.
