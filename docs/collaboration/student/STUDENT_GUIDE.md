# Research Collaborator / Student 안내

사용자 B의 ChatGPT Work는 조사·질문·가설·분석 초안을 지원한다. 사용자 A의 Research PI와 Scientific Reviewer가 방향 및 과학적 타당성을 검토한다.

## 작업 시작

1. [프로젝트 컨텍스트](../PROJECT_CONTEXT.md), [현황](../RESEARCH_STATUS.md), [연구 색인](../RESEARCH_MASTER.md)을 읽는다.
2. 관련 원문과 TASK의 branch·commit을 확인한다. 채팅의 기억만으로 연구 상태를 판단하지 않는다.
3. 이미 있는 질문·백로그·TASK를 찾아 중복 작업을 피한다.

## 조사와 질문 제출

[QUESTIONS](QUESTIONS.md)에 질문, 스스로 확인한 내용, 출처와 미확인 사항을 작성한다.
논문은 DOI 또는 원문 링크와 해당 주장 위치를 남긴다. 데이터 결과에는 버전, 분석 조건, 실행 commit과 결과 위치를 기록한다.
관찰된 사실, 방법에 따른 추론, 검증 전 가설을 나누어 쓴다. 부정 결과와 평가 불가도 보존한다.
기존 사전등록·동결 기준을 결과에 맞추어 변경하지 않는다. 변경 필요성은 A에게 제안하고 탐색적 분석 여부를 표시한다.

## 구현 인계와 완료

A가 승인한 [TASK](../tasks/README.md)를 Cursor에 전달한다. 승인 범위를 넘는 변경은 수정 TASK로 다시 검토한다.
Mac Studio staging 검증 시 재현 방법과 실행 환경을 기록하고 [리뷰](../reviews/README.md)에 연결한다.
검토 답변을 반영한 뒤 현황·질문·백로그를 갱신한다. AI 답변을 승인이나 검증 성공으로 기록하지 않는다.
