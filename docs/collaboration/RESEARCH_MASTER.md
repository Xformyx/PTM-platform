# 연구 마스터 색인

작성일: 2026-09-11. 담당: 사용자 A(PI), 사용자 B(조사·정리).
이 문서는 기존 연구 원문의 탐색을 돕는다. 과학적 결론과 우선순위를 새로 승인하는 문서가 아니다.

| 자료 | 용도 |
|---|---|
| [통합 연구 설계 v2](integrated_research_design_v2.md) | 표현 학습과 하류 귀속 추론의 합성, 주장 범위와 미해결 질문 |
| [Core A/B 동결 계약](core_ab_p2_frozen_contract_v1.md) | 기존 동결 범위 확인 |

통합 설계 v2는 자체 대체 관계를 명시한다. 다른 문서 간 우선순위는 해당 원문의 명시적 대체·동결 기록을 확인한다.
과거 문서의 완료·실패·미평가 기록은 원문 날짜와 함께 인용하며 현재 실행 결과로 바꾸어 쓰지 않는다.

## 연구 항목 등록 양식

- 연구 ID / 제목:
- 질문 / 검증 가능한 가설:
- 원문 설계 경로·절 / 기준 commit:
- 데이터 버전·독립 실험 단위·접근 위치:
- 관찰 / 추론 / 가설의 구분:
- 방법·대조군·평가 지표:
- 사전등록·동결 상태와 근거:
- 반증 조건·해석 한계:
- 담당 / PI 검토 / Reviewer 검토:
- 관련 TASK / 결과 / 리뷰 / 결정:
- 다음 행동:

신규 연구 우선순위와 현재 활성 항목은 A/B가 기존 기록을 대조한 뒤 [현황](RESEARCH_STATUS.md)에 등록한다.
