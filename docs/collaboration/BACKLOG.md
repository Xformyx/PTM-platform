## 등록·전환 규칙

새 항목에는 문제, 근거, 기대 산출물, 담당, 우선순위 제안과 관련 원문을 적는다.
A의 우선순위 결정 후 [TASK](tasks/README.md)로 구체화하고 승인 근거를 연결한다.
상태는 proposed / approved / in_progress / review / blocked / done / deferred를 사용한다.
TASK가 있으면 상세 실행 상태는 TASK 원문을 따른다. 백로그에 올리는 것만으로 구현을 시작하지 않는다.
자동화와 Orchestrator는 이 백로그에서 실행 승인하지 않으며 별도 범위 합의가 필요하다.
