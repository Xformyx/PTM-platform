## 0. 이 문서가 존재하는 이유

C2는 §9.5에서 **조건부 중심 방법 장**으로 승격되었으나 사전등록이 없었다. 강등된 C1은 완전한
사전등록을 갖는데 중심 방법은 갖지 않은 상태였다.

C1 사전등록은 두 라운드의 외부 검토를 거쳐 고쳐졌고, 고쳐진 실수는 하나로 요약된다 —
**결과를 본 뒤에 임계와 모형을 정한 것.** C2에서 같은 실수를 반복하면 중심 장이 무너진다.

이 문서는 다음을 **측정 전에** 확정한다.

```text
(1) 인증서 조건 (a)–(d) 의 정량적 판정 규칙
(2) 조건 (c) 의 예측기族 범위 — 추가·삭제 금지 목록
(3) adversary 강도 sweep 격자와 λ 선택 규칙
(4) frontier 판정 규칙
(5) 다중성 논리 — 무엇이 primary 이고 무엇이 기술적 보고인가
```

### 0.1 C2가 C1에 막혀 있지 않다는 점

C1은 `§2.1.2 form → site 집계 규칙` 미결로 동결이 막혀 있다. **C2는 이 결정에 의존하지 않는다.**
C2의 판정량은 전부 표현 공간 내부에서 계산되며 NNLS 조건 공간과의 정렬이 필요 없다. 따라서
**C1 동결 대기 중에도 C2는 진행 가능하다.** 이것이 C2를 먼저 착수하는 근거다.

단, C2가 사용하는 gate는 `key_level = "form"` 에서 계산된 값이며(§1.1), form 단위라는 사실은
C2의 결론에도 그대로 따라붙는다. §1.6에 해석 한계로 명시한다.

## 1. 대상 gate의 실제 형태 (코드 기준)

사전등록이 추상적 목표를 쓰면 구현 단계에서 조용히 달라진다. 판정 대상을 코드 수준에서 고정한다.

### 1.1 계산 경로

```text
ptm_shared/representation/benchmark.py
  _missingness_r2(embedding, missingness)          # L187
  MultiViewTemporalInput.with_additional_target_masking(...)   # feature_contract.py L259
  gates["missingness_validity"]                    # L569–595
```

동결된 설정값 (`DEFAULT_BENCHMARK_CONFIG`, 실측 산출물 `config` 블록에서 확인):

```text
artificial_mask_fraction      = 0.15
missingness_r2_max            = 0.25
missingness_pattern_ari_min   = 0.20
cluster_distance_threshold    = 0.30
minimum_cluster_size          = 2
seed                          = 0
key_level                     = "form"
minimum_observed_timepoints   = 3
latent_dim                    = 16      (D, E)
```

### 1.2 gate는 **두 개의** 하위 조건이다 — §6.3 (a)의 모호성 해소

`integrated_research_design_v2.md` §6.3 (a)는 "induced missingness R² ≤ 0.25 달성 # gate 통과"로
적혀 있다. **이것은 부정확하다.** 코드의 gate는 두 조건의 논리곱이다.

```python
retention_ok = pattern_retention_ari  >= 0.20
coverage_ok  = induced_missingness_r2 <= 0.25
passed       = retention_ok and coverage_ok
```

**사전 확정:** 조건 (a)는 `missingness_validity.passed == True`, 즉 **두 하위 조건 모두**를 뜻한다.
`induced R² ≤ 0.25` 만으로 (a)를 충족했다고 서술하지 않는다.

이 구분이 사소하지 않은 이유는 §2의 실측치가 보여준다. D는 **두 조건 모두** 실패하고
(ARI 0.035, R² 0.462), E는 **R² 조건만** 실패한다(ARI 0.974, R² 0.273). 즉 두 arm의 실패 양상이
질적으로 다르며, (a)를 R² 단독으로 읽으면 E는 "거의 통과"로 보이고 D는 "R² 문제"로 보인다.
실제로는 D는 **마스킹 하에서 군집 구조가 붕괴**하는 별개의 실패를 함께 갖는다.

### 1.3 판정은 단일 seed에 의존한다 — 다중 seed로 교체

`with_additional_target_masking(fraction=0.15, seed=config["seed"])` 이며 `seed = 0`이다. induced
mask는 site별 rate를 `uniform(0, 2×0.15)`에서 뽑고 마스킹 대상 열을 무작위 선택한다. 즉
**gate 판정값 전체가 seed 0의 단일 실현에 의존한다.**

adversary 도입 전후 차이를 이 단일 실현으로 판정하면, 관측된 차이가 방법 효과인지 mask 실현
변동인지 분리할 수 없다.

**사전 확정 — `INDUCED_MASK_SEED_SET_V1`**

```text
평가 seed        = {0, 1, 2, 3, 4}          # 5개. seed 0 은 기존 공표값과의 비교를 위해 포함
보고            = 5개 전부의 개별 값 + 중위수 + 최소·최대
(a) 통과 판정    = 중위수가 두 하위 조건을 충족  AND  5개 중 4개 이상에서 개별 통과
seed 추가 금지   = 통과가 안 될 때 seed 를 늘려 재판정하지 않는다
```

seed는 mask 실현에만 쓰이고 인코더 학습 seed는 별도로 고정한다(§12).

**측정 완료 (2026-08-21). `scripts/measure_c2_prefreeze.py`, adversary 도입 전 D arm.**

| seed | 마스킹 site | 표적=0 site | 마스킹 항목 | retention ARI | induced R² | gate |
|---:|---:|---:|---:|---:|---:|---|
| 0 | 1,911 | 833 | 2,298 | 0.035002 | **0.462393** | 실패 |
| 1 | 1,893 | 851 | 2,269 | 0.036033 | 0.555683 | 실패 |
| 2 | 1,890 | 854 | 2,290 | 0.048273 | 0.596897 | 실패 |
| 3 | 1,867 | 877 | 2,242 | 0.033791 | 0.589014 | 실패 |
| 4 | 1,924 | 820 | 2,301 | 0.040478 | 0.564178 | 실패 |

```text
retention ARI   중위수 0.036033   범위 [0.033791, 0.048273]     임계 0.20 — 전부 크게 미달
induced R²      중위수 0.564178   범위 [0.462393, 0.596897]     임계 0.25 — 전부 초과
개별 통과 0/5.  중위수 통과 아님.
공표값 재현: seed 0 에서 |Δ ARI| = 0, |Δ R²| = 0 (정확 일치)
```

**공표된 단일 seed 값이 5개 중 가장 유리한 값이었다.** seed 0의 `induced R² = 0.462`는 5개의
**최솟값**이며 중위수는 0.564다. 단일 seed 보고는 coverage 누출을 약 0.10 과소평가했다.
이것이 다중 seed 규칙을 도입한 이유이며, **C2가 고쳐야 할 양은 공표값보다 크다.**

retention ARI는 seed에 거의 무관하게 안정적으로 실패한다(0.033–0.048). 즉 D의 군집 구조 붕괴는
mask 실현의 우연이 아니다.

**재현에 필요한 정확한 호출 (기록 필수).** ablation은 주 인코더와 다른 epoch 수를 쓴다.

```text
encoder_config = {latent_dim 16, hidden_dim 64, epochs 150, seed 0, n_perturbations 5}
config         = {neighbors 10, leave_one_out False, minimum_sites 8, seed 0}
입력           = eligible_subset() 적용 (2,819 → 2,744). 미적용 시 재현 불가
출처           = workers/preprocessing/core/ptm_representation_learning.py
                 _run_bounded_ablation(), benchmark_epochs = 150
```

`epochs = 300`(주 인코더 값)으로 계산하면 `induced R² = 0.467`, `ARI = 0.035064`가 나오며 공표값과
불일치한다. **C2의 모든 arm은 위 설정으로 계산한다.**

### 1.4 R²는 예측기 개수를 보정하지 않는다 — 허용 비교만 명시

`_missingness_r2`는 `np.linalg.lstsq`로 표준화된 임베딩 + 절편을 회귀한 **표본 내 R²**다.
설계 문서 §2.5가 이미 이 지표를 **arm 간 비교 불가**로 판정했다(B는 30차원, D·E는 16차원).

**사전 확정 — 허용되는 비교**

```text
허용   D          대  D + adversary(λ)        # 동일 latent_dim = 16. 예측기 개수 동일
허용   D + λ_i    대  D + λ_j                 # sweep 내부
금지   D + adv    대  B                        # 차원 불일치. §2.5 위반
금지   D + adv    대  E                        # 차원은 같으나 view 구성이 다름(§2.5의 (b) 예외를
                                               # 인정하되 R² 절대값 비교는 하지 않고 gate 통과
                                               # 여부만 병기)
```

**latent_dim은 C2 전 과정에서 16으로 고정한다.** adversary가 유효 차원을 줄여 R²를 낮추는 것과
결합를 분리하기 위해, §6.3에서 유효 rank를 함께 보고한다.

### 1.5 과적합 하한은 이 표본에서 문제가 아니다 (실측 확인)

표본 내 R²는 예측변수 수 / 표본 수 만큼 상향 편의를 갖는다. 실측 코호트에서 확인했다.

```text
n_sites  = 2,744        (n_sites_total 2,819 중 적격 2,744)
예측변수  = 16 + 절편 = 17
잡음 하한 ≈ 17 / 2744 ≈ 0.006
```

임계 0.25 대비 무시 가능하다. **따라서 C1의 E1b에서 문제가 된 소표본 과적합은 C2에는 해당하지
않는다.** 표본 내 R²를 (a)의 legacy 지표로 유지하는 것이 정당하다. 다만 조건 (c)는 표본 외
추정을 요구한다(§4).

### 1.6 해석 한계 (필수 명시)

```text
(1) form 단위    gate 는 key_level="form" 에서 계산된다. site 단위 결론으로 확장하지 않는다.
(2) 단일 코호트  HIRc-B 단독이다. `generalization` gate 는 외부 데이터셋이 없어 미평가이며
                 C2 가 성공해도 그 gate 는 열린 상태로 남는다(§11 소관).
(3) MNAR 미검증  결측이 MNAR 이라는 것은 가정이며 이 설계로 검증되지 않는다.
```

### 2.1 교환은 D 대 E 가 아니라 **4-arm 패턴**이다 (사전등록 작성 중 발견)

설계 문서 §6.1은 교환을 D 대 E로 서술했다. 실측 산출물을 arm 전체로 확인한 결과 **더 강한
구조가 있다.**

```text
두 하위 조건을 동시에 만족하는 arm 이 하나도 없다.
그러나 각 조건은 개별적으로는 만족된다.

  retention ARI ≥ 0.20 만족   B (0.234), E (0.974)
  induced R²    ≤ 0.25 만족   A (0.007)
  둘 다 만족                  없음
  둘 다 실패                  D
```

**특히 arm A가 결정적이다.** 학습 없는 원 Track 2 궤적이 **induced R² = 0.0073**으로, 임계
0.25의 3% 수준이다. natural R²도 0.2349로 최저다.

이것이 뜻하는 바:

```text
(1) coverage 얽힘은 데이터에 내재한 것이 아니라 **표현이 도입한다.**
    원 궤적은 거의 얽혀 있지 않고, 수공 벡터(B 0.886)와 학습 표현(D 0.462)이 얽힘을 만든다.
(2) induced R² ≈ 0 은 **도달 가능한 값이다.** A 가 존재 증명이다.
    따라서 임계 0.25 는 달성 불가능한 목표가 아니다.
(3) A 는 그 대가로 아무것도 학습하지 않는다 (ΔR² −0.0008, 50% 우세, p = 0.776).
    그리고 retention ARI 0.167 로 **다른 쪽 조건에서 실패한다.**
```

**따라서 C2의 표적은 D 대 E의 중간이 아니라, 네 arm이 각각 다른 실패를 하는 공간에서 두 조건을
동시에 만족하는 점을 찾는 것이다.** 이 서술을 §6.1의 2-arm 서술보다 우선한다.

```text
C2 의 목표 =  D 의 예측력 (조건 b)
              AND  B·E 의 마스킹 안정성 (ARI ≥ 0.20)
              AND  A 의 coverage 분리 (induced R² ≤ 0.25)
```

**차원 혼입 주의:** A는 12차원, B는 30차원, D·E는 16차원이다. §1.4에 따라 R² 절대값의 arm 간
비교는 판정에 쓰지 않는다. 위 관찰은 **판정이 아니라 목표 설정의 근거**로만 쓰며, 0.007 대
0.462의 차이가 12 대 16 차원 차이로 설명되지 않는다는 점을 병기한다(예측변수 4개 추가로
설명되는 분산이 0.45에 이르지는 않는다는 논거이며, 형식적 증명은 아니다).

### 2.2 두 coverage 지표의 arm 순위가 반대라는 사실 (필수 병기)

```text
induced R²  (마스킹 후 재적합)   A 0.007  <  E 0.273  <  D 0.462  <  B 0.886
natural R²  (원 결측률)          A 0.235  <  B 0.388  <  E 0.409  <  D 0.849
```

**어느 arm이 coverage를 가장 많이 인코딩하는가는 지표에 따라 뒤집힌다.** A는 두 지표 모두에서
최저이나 **B와 D의 순위가 반대다.** 설계 문서 §2.8의 "production handcrafted(B)가 최악"이라는
서술은 **induced 기준에서만** 성립하며, natural 기준에서는 **D가 최악이고 B는 A 다음으로 좋다.**

**사전 확정:** C2의 판정은 gate가 쓰는 **induced** 지표로 한다. natural R²는 **모든 표에 병기하며
판정에 쓰지 않는다.** 어느 한쪽만 보고하는 것을 금지한다. 두 값이 반대 방향으로 움직이면
그것 자체를 결과로 보고한다.

### 2.3 induced 표적의 영값 편중 (동결 전 측정 필수)

`induced.mean(axis=1)`이 회귀 표적이다. `minimum_remaining = 3` 때문에 관측 시점이 3개 이하인
site는 마스킹되지 않으며, `count = round(n_obs × rate)`가 0으로 반올림되는 site도 마스킹되지
않는다. **이들의 표적값은 정확히 0이다.**

**측정 완료 (2026-08-21, seed 0). 우려가 확인되었으나 원인은 예상과 달랐다.**

표적은 사실상 **세 값만 갖는다.**

```text
0 개 마스킹 → 표적 0      833 site  (30.36%)
1 개 마스킹 → 표적 1/6  1,524 site  (55.54%)
2 개 마스킹 → 표적 2/6    387 site  (14.10%)
```

**즉 `induced_missingness_r2`는 연속 coverage 비율에 대한 회귀가 아니라 거의 3값 순서형
표적에 대한 회귀이며, 분산의 대부분은 "마스킹되었는가"(0 대 1/6)에서 온다.** R² 0.462는
"얼마나"가 아니라 주로 "여부"를 설명한다. 이 사실을 결과 서술에 필수 병기한다.

**관측 시점 수와의 구조적 교란은 작다.** 우려했던 것은 `minimum_remaining = 3` 때문에 표적이
natural coverage의 함수가 되는 것이었다.

| 관측 시점 | site | 표적=0 | 표적=0 비율 | 평균 표적 |
|---:|---:|---:|---:|---:|
| 3 | 66 | 66 | **1.0000** | 0.0000 |
| 4 | 109 | 41 | 0.3761 | 0.1040 |
| 5 | 241 | 92 | 0.3817 | 0.1030 |
| 6 | 2,328 | 634 | 0.2723 | 0.1490 |

관측 시점이 3개인 site는 **구조적으로 전부 표적 0**이나 66개(2.4%)에 불과하다. 나머지 계층의
영값 비율은 0.27–0.38로 비슷하다. **따라서 교란은 존재하나 induced R²의 주 동인이 아니다.**
이 측정으로 §2.3의 우려 중 "영값 편중"은 확인되었고 "natural coverage 교란"은 기각되었다.

**사전 확정 — 보고 의무.** 위 두 표(값 분포, 계층별 영값)를 C2의 모든 arm에서 산출해 병기한다.
adversary가 표적 분포를 바꿀 수는 없으나(마스킹은 인코더와 무관), **arm 별로 R²가 무엇을
설명하는지 독자가 판단할 수 있어야 한다.**

## 3. 방법 — coverage adversary 명세 (사전 확정)

### 3.1 구조

현 인코더는 NumPy 전용 수동 역전파 오토인코더다(`encoder.py`, 2 은닉층, tanh, Adam, full-batch,
300 epoch, lr 0.01). 여기에 gradient reversal 헤드를 붙인다.

```text
adversary   g : latent(16) → 표적           # 선형 + tanh 은닉 1층. 은닉 폭 16
표적        m = 인코더에게 주어진 입력 자체의 site 별 결측률
            = 1 − input.target.observed.mean(axis=1)
목적        adversary   :  min  MSE(g(z), m)
            encoder     :  min  recon + smooth + l2  −  λ · MSE(g(z), m)
구현        full-batch 동시 갱신. gradient reversal 계수 λ
```

> **방법 개정 (2026-08-21, E4 착수 전).** §10.5의 탐색적 진단에서 **선형 회수율만 낮추고 국소
> 회수율은 그대로 남는 구성이 실재함**이 확인되었다(P1 0.086 대 kNN 0.598). 위의 단일 헤드
> (선형 + tanh 은닉 1층)는 매끄러운 비선형까지만 겨냥하므로 kNN이 이용하는 국소 구조를 남길
> 위험이 크다. 따라서 **adversary 헤드를 다음으로 강화한다.**
>
> ```text
> 헤드 1   선형 + tanh 은닉 1층 (은닉 16)          # 기존. 전역·매끄러운 성분
> 헤드 2   RFF 512차 사상 위의 선형 헤드            # P4 와 같은 사상. 매끄러운 비선형
> 결합     encoder 는 두 헤드의 손실 합에 대해 gradient reversal
> ```
>
> **이는 방법 변경이며 판정 규칙 변경이 아니다.** 조건 (c)의 족 목록·임계·(a)–(d) 판정은 §14.2
> 동결분에서 바뀌지 않는다. 국소(kNN) 성분에 직접 대응하는 미분 가능한 헤드는 없으므로,
> **kNN 회수율이 (c)에서 남을 위험은 여전히 열려 있고 그것이 §13의 반증 분기 2다.**

> **방법 개정 2 — 최적반응 헤드 (2026-08-21, E4 판정 전).** 위의 두 헤드를 **동시 하강**으로
> 학습시켜 λ 격자(§7.1)를 돌린 결과, adversary 손실은 λ와 함께 올라갔으나
> **gate 지표는 움직이지 않았다.**
>
> | λ | adversary 손실 (헤드 2개 합) | 같은 임베딩의 최소제곱 R² (결합 표적) |
> |---:|---:|---:|
> | 0 | 1.359 | 0.798 |
> | 5 | 2.064 | 0.721 |
>
> 손실 2.06은 표적이 단위 분산이므로 **두 헤드가 평균 예측 수준으로 무력화되었다**는 뜻이다.
> 그런데 같은 임베딩에 최소제곱을 다시 적합하면 같은 표적이 R² 0.72로 회수된다. 즉
> **정보는 그대로 있고 헤드만 못 찾은 것이다.** 원인은 min-max의 비정상성이다 — 인코더가 매
> step 움직이므로 하강 헤드는 최종 표현에 대한 최적해에 도달하지 못한다.
>
> **이는 우연한 구현 문제가 아니라 구조적 문제다.** gate 지표(`_missingness_r2`)와 조건 (c)의
> 예측기族은 모두 **최적반응 적합**이다. 따라서 동시 하강 헤드로 학습한 인코더는 판정 대상을
> 한 번도 겪지 않는다. 이를 고치기 위해 헤드를 매 epoch 닫힌 형태로 정확히 최소화한다.
>
> ```text
> 헤드 1   절편 포함 무벌점 최소제곱 (numpy.linalg.lstsq)   # gate 지표와 같은 함수형
> 헤드 2   RFF 512차 위 ridge, 벌점 1e-3 고정 (numpy.linalg.solve)
> 기울기   envelope theorem — 헤드가 최소해이므로 dL*/dU = ∂L/∂U|_{w*}
> 대역폭   첫 호출에서 동결. 재추정하면 사상이 U 의 함수가 되어 기울기가 틀린다
> ```
>
> **판정 규칙·임계·격자는 바뀌지 않는다.** 검증: 두 모드의 잠재·파라미터 기울기를 유한차분으로
> 확인했고(상대오차 < 1e-8), 최적반응 손실이 동시하강 손실보다 낮음을 회귀 테스트로 고정했다
> (`scripts/verify_coverage_adversary_gradients.py`, `workers/tests/test_coverage_adversary.py`).
>
> **남는 해석 한계.** 헤드 2의 벌점은 매 epoch 내부 CV를 돌 수 없어 고정값이고, 두 헤드는
> **표본 내** 적합이다. 조건 (c)의 P2–P5는 벌점을 내부 CV로 고르는 **표본 외** 교차적합이므로
> 둘은 같은 양이 아니다. **최적반응 헤드를 이긴 것이 (c) 통과를 뜻하지 않는다.**

**표적은 `induced` 배열이 아니라 입력의 관측 행렬에서 계산한다.** 이 구분이 핵심이다.

```text
비마스킹 적합   표적 = natural 결측률
마스킹 재적합   표적 = natural + induced 를 합한 결측률   ← gate 가 재는 것과 같은 대상
```

즉 adversary는 `induced`를 **따로 보지 않으면서** gate가 측정하는 양을 직접 겨냥한다. 인코더는
자신이 받은 입력의 결측 패턴을 인코딩하지 않도록 학습되며, 마스킹 재적합에서도 같은 penalty가
적용된다. **`induced` 배열 자체는 어떤 손실에도 들어가지 않는다** — 들어가면 gate가 자기 표적을
최적화한 결과가 되어 무효다. 이 분리를 테스트로 강제한다(§12).

### 3.2 결정성 제약

```text
NumPy 전용 유지. PyTorch 도입하지 않는다 (§6.6 — worker 의존성 정책 변경 사안)
seed 고정. full-batch 이므로 minibatch 잡음 없음
adversary 초기화 seed 를 인코더 seed 와 분리해 기록
매 epoch 의 recon / smooth / adversary loss 를 history 에 기록
```

### 3.3 min-max가 수렴하지 않을 경우 (사전 확정된 대안 경로)

§6.6이 미검증 위험으로 지목한 부분이다. **실패 판정과 대안 전환 조건을 미리 정한다.**

```text
발산 판정   최근 50 epoch 의 recon loss 가 초기 50 epoch 평균의 2 배를 초과
            또는 adversary loss 가 단조 증가하며 recon 이 개선되지 않음
1차 대응    λ 를 격자 내에서 낮춤 (§7.1). 격자 밖 값 사용 금지
2차 대응    MI 상한 penalty 로 전환. 전환 시 이 문서에 개정으로 기록하고
            전환 시점이 **결과 열람 후**이면 해당 분석은 탐색적(exploratory)으로 표기
```

**전환은 자유이나 무기록 전환은 금지다.** 전환 사실과 시점이 §14 개정 로그에 남아야 한다.

### 4.1 族 목록

**scikit-learn은 의존성이 아니다.** `benchmark.py`는 군집·ARI를 직접 구현했고 주석에

| id | 예측기 | 포착 대상 | 추정 |

| P2 | Ridge, 벌점 내부 CV | 전역 선형, 정칙화 | 5-fold 표본 외 |
| P3 | kNN 회귀, k ∈ {5, 10, 20} | 국소 구조 | 5-fold 표본 외 |

**P4의 RFF 근사 선언 (2026-08-21, 구현 확인 단계).** 정확한 RBF kernel ridge는 n ≈ 2,700에서
O(n³)이라 5-fold × 내부 CV에 부적합하다. random Fourier feature 512차원으로 근사하며
**차원과 seed를 고정하므로 결정적이다.** 근사이므로 정확한 kernel ridge보다 표현력이 낮을 수
있다는 점을 해석 한계로 병기한다. 이 선언은 adversary 측정 전에 이루어졌다.

### 4.1.1 측정 완료 — adversary 도입 전 기준선 (2026-08-21, D arm, seed 0)

| 예측기 | 표본 외 R² | 순열 귀무 평균 | 귀무 최대 | 초과분 |
|---|---:|---:|---:|---:|
| P2 ridge | 0.451783 | −0.002392 | 0.002183 | 0.454175 |
| **P3 kNN** | **0.624668** | −0.066195 | −0.043819 | 0.690863 |
| P4 RFF kernel ridge | 0.619989 | −0.003371 | 0.001637 | 0.623360 |
| P5 quadratic ridge | 0.606825 | −0.006846 | −0.000535 | 0.613671 |

```text
族 최대 = 0.624668     임계 0.25 → (c) 미충족 (adversary 도입 전이므로 예상된 결과)
참고: P1 표본 내 선형 = 0.462393 (gate 지표)
     P2 표본 외 선형 = 0.451783 → 표본 내·외 차이가 0.011 뿐. §1.5 의 과적합 무관 확인과 일치
```

**비선형 예측기가 선형보다 훨씬 잘 회수한다 (0.625 대 0.452).** 즉 **gate 지표(P1)는 실제 회수
가능성을 0.16 과소평가한다.** 이것이 조건 (c)를 별도로 둔 이유이며, 다음을 뜻한다.

```text
adversary 가 선형 성분만 제거하면 (a) 는 통과하고 (c) 는 실패할 수 있다.
그 경우가 §8 의 "경고 신호"이며 §13 의 반증 분기 2 로 간다.
C2 가 넘어야 하는 실제 값은 0.462 가 아니라 0.625 다.
```

순열 귀무가 네 族 모두 0 근처(|값| ≤ 0.07)이므로 **구현이 무편향임이 확인되었다.**

### 4.2 판정 규칙

```text
(c) 통과 =  max over {P2, P3, P4, P5} 의 표본 외 R²  ≤  0.25
            AND  각 族의 (R² − 순열 귀무 R²) 를 병기
P1 은 (a) 의 legacy 지표로만 쓰고 (c) 의 최대값 계산에 넣지 않는다
        (표본 내 · 표본 외를 한 최대값에 섞지 않는다)
```

임계 0.25는 gate와 같은 값을 **더 정직한 추정량에 적용**한 것이다. 새 임계를 도입하지 않기
위한 선택이며, 표본 외 R²는 음수가 될 수 있어 통과가 표본 내보다 쉬워질 수 있다는 점을
해석 한계로 병기한다.

### 4.3 주장 범위 (필수)

族이 **선형 · 국소 · 매끄러운 비선형**을 덮고 **축 정렬 분할 앙상블(tree/GBM)을 덮지 않는다.**
따라서 (c) 통과 시 허용되는 서술은 다음뿐이다.

```text
허용   "사전등록된 예측기族 중 어느 것도 잔여 mask 를 회수하지 못했다"
금지   "mask 는 회수 불가능하다"
금지   "표현이 coverage 로부터 독립이다"
```

tree 계열을 넣으려면 `scikit-learn`을 의존성에 추가해야 하며, 이는 **별도 판단 사항**으로
남긴다(§14 미결).

## 5. 인증서 조건의 정량적 판정 (사전 확정)

### 5.1 (a) gate 통과

```text
missingness_validity.passed == True
  = pattern_retention_ari  >= 0.20
  AND induced_missingness_r2 <= 0.25
  AND §1.3 의 다중 seed 규칙 충족 (중위수 통과 + 5 중 4 이상 통과)
```

### 5.2 (b) 예측력을 팔지 않았음

D의 출발점은 ΔR² = +0.0271, 24/24 짝 우세, p = 0.0001이다(§2.6). 유지 기준을 **지금** 정한다.

```text
(b) 통과 =  짝지은 sign-flip 검정에서 B 대비 p < 0.05        # 동일 24 짝
            AND  ΔR² >= 0.5 × 0.0271 = 0.01355               # 이득의 절반 이상 보존
```

`0.5`는 판단이며 **측정 전에 선언한다.** 근거: 절반 미만이면 "예측력을 유지했다"는 서술이
방어되지 않는다고 사전에 판단했다. 측정 후 이 계수를 바꾸지 않는다.

**해석 한계 병기 필수:** baseline이 이미 R² = 0.924인 과제에서의 +0.027이다. 상대 이득이 작다는
사실을 (b) 통과와 함께 항상 보고한다.

§4.2.

### 5.4 (d) 교환의 실제 해소

```text
(d) 통과 =  (b) 의 두 조건        # D 의 예측력 쪽
            AND  pattern_retention_ari >= 0.20   # E 의 마스킹 안정성 쪽
```

(d)는 (a)·(b)의 논리적 부분집합이 아니다. (a)의 ARI 조건과 (b)를 **같은 arm에서 동시에**

관찰에 대한 직접적 답이며, 이것이 Chapter 3의 핵심 표가 된다.

### 5.5 C2 성공의 정의 (사전 확정)

```text
C2 성공 =  primary arm 에서 (a) AND (b) AND (c) AND (d) 동시 충족
           AND  E8 (adversary 없는 대조) 가 같은 것을 달성하지 못함
```

**OR 성공을 금지한다.** 네 조건 중 일부만 충족한 경우를 "부분 성공"으로 서술하지 않는다.
그 경우는 §13의 반증 분기로 간다.

## 7. E5 — adversary 강도 sweep과 frontier

### 7.1 격자 (사전 확정. 격자 밖 값 사용 금지)

```text
λ ∈ {0, 0.05, 0.1, 0.25, 0.5, 1.0, 2.0, 5.0}     # 8 점. λ = 0 은 D 재현 대조
```

`λ = 0`이 §2의 D 실측치를 재현하지 않으면 구현 오류이며, 재현 확인을 회귀 테스트로 고정한다.

### 7.2 frontier 판정 규칙

```text
축      x = induced R² (낮을수록 좋음)      y = 프로브 ΔR² (높을수록 좋음)
보고    8 점 전부. 중간 점 보간 금지
판정    (a)+(b) 를 동시 만족하는 점이 존재하는가 — 존재 여부만이 판정 대상
```

frontier의 형태 자체가 결과다. 만족점이 없으면 §13의 "교환이 근본적" 분기로 간다.

```text
                       **§9 원문은 4·5·6 만 적었다.** 모집단 필터가
                       `minimum_observed_timepoints = 3` 이므로 3 이 존재할 수 있고,
                       빼면 층화가 모집단을 덮지 못한다.  3 을 추가하고 이 사실을 기록한다

층 (3) natural 결측률   `missingness_rate()` 의 사분위 Q1–Q4 (모집단 내 경계)
```

층화 대상 지표는 네 개다. **모두 기존 정의를 그대로 부분 모집단에 적용한다** — 새 정의를
만들면 층별 값과 전체 값을 비교할 수 없다.

```text
M1  induced missingness R²    조건 (a) coverage 축.  층 내부에서 회귀를 **다시 적합**한다
                              `benchmark._missingness_r2` 를 그대로 호출한다 (정의 표류 방지)
M2  족 최대 회수 R²           조건 (c).  `coverage_probes.residual_mask_recoverability`
                              를 층 부분집합에 호출한다.  族 목록은 §4.1 그대로
M3  FM_precision              C3 지표.  **양 종단이 층 안에 있는 쌍**으로 제한한다
M4  retention ARI             마스킹 전후 군집 일치.  같은 쌍 제한을 적용한다
```

```text
집계  층별 값 + 전체 값을 **항상 병기**한다.  median 단독 금지 (§9 원문)
      층 간 산포를 전체 값과 대조해 "전체 요약이 오도하는가"를 판단 근거로 제시한다
판정  **없다.** §11 이 E7 을 기술적 보고로 배정했고 임계를 선언하지 않았다.
      어느 층에서 인증서가 충족되어도 C2 성공의 근거가 되지 않는다 (§11 금지 항목)
```

**임계를 만들지 않는 것이 의도된 것이다.** 층을 사후에 고를 수 있으므로 층별 판정을 허용하면
다중 비교가 된다. E7이 답하는 질문은 "충족되는 층이 있는가"가 아니라 **"전체 요약이 층 구조를
가리고 있는가"**다.

#### 9.2.1 M1·M2 — coverage 인코딩은 완전 관측 층에 집중되어 있다

변한다.** 이 교란은 현재 설계로 분리되지 않는다. 분리하려면 마스킹 예산을 관측 수에
비례시키지 않는 대체 프로토콜이 필요하며, 그것은 §4의 동결된 프로토콜 변경이므로 여기서
하지 않는다.

#### 9.2.3 M3 — 층별 FM_precision은 기저율 없이 해석되지 않는다

**첫 실행 뒤에 비교 불가 기저율을 추가했다.** 층별 FM_precision만으로는 값을 읽을 수 없었기
때문이다. 임계가 없는 기술 통계이므로 어떤 primary 판정도 이 추가에 영향받지 않는다.

| 층 | n | FM_precision | 비교 불가 기저율 | 비 |
|---|---:|---:|---:|---:|
| **(전체)** | 2,744 | **0.1042** | **0.2020** | **0.52** |
| U-confirmatory | 2,246 | 0.0491 | 0.0814 | 0.60 |
| U-low-baseline | 268 | 0.4743 | 0.5371 | 0.88 |
| U-denovo | 230 | 0.7949 | 0.8230 | 0.97 |
| 관측 6/6 | 2,328 | 0.0313 | 0.0423 | 0.74 |
| 관측 5/6 | 241 | 0.6335 | 0.7215 | 0.88 |
| 관측 4/6 | 109 | 0.9760 | 0.9919 | 0.98 |

전체 기저율 0.2020은 `c3_prereg_v1.md` §12.3의 전역 20.2%와 일치한다. 독립 경로에서 같은
값이 나온 교차 확인이다.

두 가지가 읽힌다.

1. **비가 어느 층에서도 1을 넘지 않는다.** 군집이 비교 불가 쌍을 기저율보다 **더 선호하지
   않는다.** 이것은 arm D의 군집이 비교가능성을 적극적으로 위반하지는 않는다는 뜻이다.
2. **전체의 0.52라는 여유는 층 혼합에서 나온 것이다.** 기저율 0.042인 큰 층과 기저율 1.0에
   가까운 작은 층을 섞으면, 각 층에서 비가 0.74–1.00이어도 합산 비는 0.52로 내려간다.
   Simpson 형 역전이다.

#### 9.2.4 이것이 C3의 λ 취약성과 E11 적대성을 설명한다

`c3_prereg_v1.md` §15·§16이 남긴 두 미해명 사실 — E9의 개선이 λ = 1.0에서만 성립한 것과
E11에서 C2+C3이 C2 단독보다 나빴던 것 — 에 대해 이 층화가 기전 수준 설명을 준다.

```text
비교 불가가 밀집한 층(관측 ≤ 4/6)에서 기저율이 0.99–1.00 이다
→ 그 층 안에서는 어떤 병합이든 거짓 병합이며, **줄일 여지가 구조적으로 없다**
→ 남은 여지는 층 간 쌍에만 있고, 그것은 군집을 층 경계로 쪼개는 것과 같다
→ 그래서 C3 의 이득이 자명성 guard(G2, 효율)와 정면으로 경쟁하며 λ 에 취약하다
```

**이 설명은 사후에 얻은 것이므로 탐색적이다.** C3의 어떤 primary 판정도 이 설명으로
갱신되지 않는다(§3의 단방향 규칙). Chapter 4의 특성화 내용으로만 쓴다.

## 10. E8 — adversary 없는 대조 (veto 실험)

§6.5의 세 번째 반증 조건 — "adversary 없이 하이퍼파라미터 조정만으로 (a)+(b)가 달성되면 C2의
방법 기여 소멸" — 은 설계 문서에 실험이 배정되어 있지 않았다. **배정한다.**

### 10.1 격자 (사전 확정)

```text
latent_dim          ∈ {8, 16, 32}
l2                  ∈ {기본값 ×0.1, ×1, ×10}
input_mask_fraction ∈ {기본값 ×0, ×1, ×2}
                    → 3 × 3 × 3 = 27 구성
```

`latent_dim`을 여기서는 변화시킨다. §1.4의 16 고정 규칙은 **adversary arm 내부의 비교**에 대한
것이고, E8은 "하이퍼파라미터만으로 되는가"를 묻는 대조이므로 차원 변경이 허용 대상에 포함된다.
단 E8의 R² 값은 차원이 다르므로 **E4의 R²와 직접 비교하지 않고 gate 통과 여부로만 판정한다.**

### 10.2 예산 동등성 (필수)

```text
E8 구성 수 27  ≥  E5 격자 점 수 8       # 충족
E8 에 적은 예산을 주고 "하이퍼파라미터로는 안 된다"고 결론하면 불공정 대조다.
```

### 10.3 판정

```text
E8 의 어느 구성이든 (a)+(b)+(c) 를 충족하면
  → C2 의 방법 기여 소멸. adversary 는 불필요했다는 뜻
  → 그 사실을 보고하고 C2 를 방법 장에서 강등
```

**E8은 C2를 실패시킬 수만 있고 성공시킬 수 없다.** 비대칭이 의도된 것이다.

### 10.4 실행 결과 (2026-08-21) — **veto 발동하지 않음**

`scripts/run_c2_e8_hyperparameter_control.py`. 27 구성 × 5 seed = 162 회 적합, 209초.

```text
조건 (a) 통과 구성 = 0 / 27
```

`l2`는 100배 범위에서 어떤 지표도 사실상 움직이지 않았다(격자의 이 축은 무정보였다).
나머지 두 축의 구조는 명확하다.

| latent_dim | 중위수 retention ARI | 중위수 induced R² (P1) | ARI 조건 | R² 조건 |
|---:|---:|---:|---|---|
| 8 | 0.033 – 0.111 | **0.119 – 0.154** | 전부 실패 | **전부 통과** |
| 16 | 0.036 – 0.053 | 0.547 – 0.580 | 전부 실패 | 전부 실패 |
| 32 | 0.023 – 0.048 | 0.629 – 0.640 | 전부 실패 | 전부 실패 |

```text
induced R² (P1)   latent_dim 에 대해 단조 증가          8 → 16 → 32 : 0.13 → 0.57 → 0.64
retention ARI     input_mask_fraction 에 반응            0.0 → 0.15 → 0.30 : 0.033 → 0.079 → 0.111
                  (latent_dim = 8 기준. 3 배 개선이나 임계 0.20 에 미달)
가장 가까운 구성   latent_dim 8, l2 1e-4, in_mask 0.30 → ARI 0.111, R² 0.119
```

**판정: (a) 통과 구성이 없으므로 veto 발동하지 않는다. C2의 방법 기여는 소멸하지 않았다.**
이것은 필요조건이며 adversary가 성공한다는 뜻이 아니다(§10 서두).

**§14.1.1의 우려는 부분적으로만 현실화되었다.** 차원 축소가 gate의 R² 조건을 통과시킨다는 예측은
맞았다(latent_dim 8에서 0.119). 그러나 **retention ARI 조건에서 전부 막혔다.** 즉 E8 격자에서
**구속 조건은 coverage 누출이 아니라 마스킹 하의 군집 구조 안정성이다.**

### 10.5 탐색적 진단 — gate 지표가 통과해도 mask 는 회수된다

> **사전등록 없음. 결과 열람 후 착수한 exploratory 분석이며 primary 판정으로 승격하지 않는다**
> (§11). `scripts/probe_c2_low_dimension_regime.py`.

§10.4에서 `latent_dim = 8`이 gate의 R² 조건을 통과했으므로, 그 구성에서 조건 (c)와 (b)가
어떻게 되는지 확인했다.

| 구성 | P1 (gate, 표본 내 선형) | P2 ridge | **P3 kNN** | P4 kernel | P5 quad | 프로브 ΔR² | p |
|---|---:|---:|---:|---:|---:|---:|---:|
| latent 8, in_mask 0.30 | **0.046** | 0.037 | **0.618** | 0.467 | 0.216 | 0.0119 | 0.0001 |
| latent 8, in_mask 0.15 | **0.086** | 0.076 | **0.598** | 0.461 | 0.219 | 0.0182 | 0.0001 |
| latent 16, in_mask 0.30 | 0.445 | 0.433 | **0.622** | 0.635 | 0.612 | 0.0160 | 0.0001 |
| latent 16, in_mask 0.15 (원 D) | 0.462 | 0.452 | **0.625** | 0.620 | 0.607 | 0.0271 | 0.0001 |

**kNN 회수율은 0.598 – 0.625로 거의 변하지 않는다.** latent_dim, `input_mask_fraction`,
`l2`를 어떻게 바꾸어도 마스크는 임베딩에서 약 60% 회수된다.

```text
latent_dim 8 에서 일어난 일
  gate 지표 P1     0.462 → 0.086     (5.4 배 감소. gate 통과)
  실제 회수 (kNN)  0.625 → 0.598     (사실상 변화 없음)
  → coverage 인코딩이 제거된 것이 아니라 **비선형·국소 구조로 옮겨간 것이다.**
```

**이것이 이 프로젝트에서 gate 자체에 대한 발견이다.** 배포된 `missingness_validity` gate는
표본 내 선형 회귀만 쓰기 때문에, **coverage 인코딩을 제거하지 않고 비선형화하는 것만으로 통과될
수 있다.** 조건 (c)를 예측기族으로 정의한 사전등록 결정이 이 사례로 정당화되었다 — (c)가 없다면
`latent_dim = 8` arm은 "coverage 분리 성공(0.086!)"으로 보고되었을 것이다.

`latent_dim = 8, in_mask = 0.15`는 예측력도 유지한다(ΔR² 0.0182 ≥ 0.01355, 24/24 우세,
p = 0.0001). **즉 (a)의 R² 조건 · (b)를 동시에 만족하면서 (c)를 크게 위반하는 구성이 존재한다.**

**해석 한계.** 단일 seed(0) 진단이며 4개 구성만 본다. E8의 정식 판정은 §10.4다. 이 표로
"latent_dim을 낮추면 안 된다"고 결론하지 않는다 — 낮춰도 실제 누출이 줄지 않는다는 것이지,
낮추는 것이 해롭다는 것이 아니다.

```text
인코더 학습 seed        = 0 (고정). 별도 기록
adversary 초기화 seed   = 1 (고정). 인코더와 분리
```

산출 레코드에 필수 기록: 위 seed 전부, NumPy 버전, dtype, epoch별 3종 loss,
adversary 수렴 판정 결과(§3.3), 유효 rank.

**코드로 강제할 사항:** induced mask가 학습 경로에 도달하지 않음을 테스트로 검증한다
(§3.1). 이 테스트 없이 결과를 보고하지 않는다.

### 12.1 발견된 결정성 결함 — 프로브 분할 salt (2026-08-22)

`fair_probe.py`의 분할 RNG seed 는 `(config seed, 가린 시점, arm, 인코더 seed, 분할 index)`로
구성되는데, arm 성분이 **`hash(arm)`** 이었다. Python 은 `PYTHONHASHSEED`가 설정되지 않으면
문자열 해시를 프로세스마다 salt 하며 **정본 컨테이너는 설정하지 않는다.**

```text
결과   같은 코드·같은 seed·같은 입력이 실행마다 다른 train/test 분할을 뽑았다
영향   프로브 절대값(ΔR², 각 arm 의 mean R²)이 실행 간 재현되지 않는다
무영향 한 실행 내부의 짝지은 비교. 두 arm 이 같은 분할을 공유하므로 sign-flip 검정은 유효하다
       gate 지표(induced R², ARI). benchmark.py 경로이며 이 seed 를 쓰지 않는다
```

**흩어짐 정량화** (`scripts/quantify_probe_split_sensitivity.py`, λ = 0, salt 4점):

| salt | ΔR² | 우세 짝 |
|---:|---:|---:|
| 0 | 0.01558 | 23/24 |
| 1 | 0.01876 | 24/24 |
| 2 | 0.01773 | 24/24 |
| 3 | 0.01563 | 24/24 |

범위 폭 0.00318, 실행 간 sd 0.00158. **fold sd(≈0.008)를 √24로 나눈 값은 실행 간 흩어짐의
추정치가 아니다** — fold 들이 인코더 적합을 공유해 독립이 아니기 때문이며, 그것이 이 측정을 한
이유다.

**수정:** `crc32(arm)`으로 교체(`_arm_seed_component`). ARI 라벨 인코딩의 `hash(label)`도 순서
기반 정수로 교체했으나 **ARI 는 라벨 재명명에 불변이므로 값은 바뀌지 않는다.**

**§7.2.1 의 8 점은 한 프로세스에서 산출되어 같은 salt 를 공유하므로** λ 에 대한 추세는 이 결함에
영향받지 않는다. 절대값 비교는 위 흩어짐과 함께 읽는다.

**모든 분기에서 남는 것이 있다.** C2 실패가 Chapter 3의 공백을 뜻하지 않으며, §9.5의 "조건부"가
그 뜻이다. 다만 실패 시 Chapter 3은 방법 장이 아니라 **한계 기술 장**이 된다.

### 13.1 실제로 발동한 분기 (2026-08-21)

**분기 2 가 발동했다** — "E6에서 비선형 族이 mask 회수 → (c) 미충족". 다만 표의 서술
("adversary 가 선형 성분만 제거")보다 좁게 발동했으므로 결론 문구를 정확히 고쳐 쓴다.

```text
사전등록 문구   "선형 분리는 가능하나 불충분"
실측에 맞는 문구  "매끄러운 함수족 전체에 대한 분리는 가능하나, 국소(최근접 이웃) 성분은
                 gradient reversal 로 닿지 않는다"
```

동시에 **분기 1 은 발동하지 않았다.** frontier 에 (a)+(b) 동시 만족점이 없는 것은 사실이나
그 원인이 §2.1 의 교환이 아니다 — coverage 축(induced R²)은 0.564 → 0.042 로 해결되었고,
막힌 것은 마스킹 하 군집 안정성(ARI)이며 그것은 arm D 의 출발점 문제다(§6.2). 따라서
**"교환이 근본적"이라고 서술하지 않는다.** 그 서술은 실측과 어긋난다.

**분기 6("C2 arm 이 A 와 사실상 같아짐")도 발동하지 않았다.** λ = 0.05 의 유효 rank 는 6 이고
군집 16 개로 A(rank 12, 군집 97)와 구조가 다르다. adversary 는 표현을 원 궤적으로 되돌린 것이
아니라 매끄러운 coverage 성분만 제거했다.

### 13.2 남는 것 — Chapter 3 의 내용

C2는 방법 장이 아니라 한계 기술 장이 된다. 다음 네 가지가 방어 가능한 결과다.

```text
1  최적반응 adversary 는 coverage 의 매끄러운 성분을 제거한다
   induced R² 0.564 → 0.042, 유효 rank 유지. 차원 붕괴로 얻은 것이 아니다.
2  국소 성분은 남는다
   kNN 회수율 0.625 → 0.513 (−17.9%). 매끄러운 족을 전부 제거한 뒤에도 출발점 회수력의
   82% 가 남고 임계 0.25 의 두 배를 넘는다.
   → "coverage 인코딩은 환원 불가능하게 국소적이다"
3  배포된 gate 는 이 구분을 하지 못한다
   P1 기준으로는 λ = 0.05 에서 통과. (c) 없이는 성공으로 오보고된다.
   → 조건 (c) 를 예측기族으로 정의한 사전등록 결정의 정당화
4  min-max adversary 는 판정 지표가 최적반응일 때 구조적으로 약하다
   동시 하강 헤드에서는 adversary 손실만 오르고 gate 는 불변이었다 (§3.1 개정 2).
   → 방법론적 지적. adversary 설계 시 판정 지표의 추정 방식을 맞춰야 한다
5  gate 의 retention ARI 하위 조건은 arm D 에서 마스킹 강건성을 재지 않는다 (§13.3)
   마스킹 전후 ARI(0.035) 가 인코더 seed 만 바꾼 ARI(0.043–0.067) 보다 **낮다**.
   → adversary 로 이 조건을 통과할 수 없었던 이유. 지표 타당성 문제이며 방법 실패가 아니다
```

**주장 금지 (재확인).** 위 어느 것도 "coverage 분리에 성공했다"가 아니다. 1 은 부분 성공이고
2 가 그것을 무효화한다. C2 의 인증서는 충족되지 않았다.

```text
마스킹은 artificial_mask_fraction 0.15, induced mask seed 0 (GATE_PROBE_PARAMETERS)

  자기 대조 (건전성 검사)            ARI = 1.0
```

**데이터의 15%를 가리는 것이 인코더 seed 를 바꾸는 것보다 군집을 덜 흔든다.** 따라서

```text
이것이 바꾸는 것과 바꾸지 않는 것

  바꾼다      "adversary 가 ARI 조건을 통과하지 못했다" 의 해석.
              그 조건은 coverage 와 무관한 양(군집의 seed 불안정)을 재고 있었다
  바꾸지 않는다  C2 의 판정.  §13.2 의 2(국소 성분 잔존)가 독립적으로 인증서를 부정한다.
              ARI 조건이 타당했더라도 C2 는 통과하지 못했다
```

**임계를 바꾸지 않는다.** `missingness_pattern_ari_min`은
`integrated_research_design_v2.md` §8.2에서 동결되었고 결과를 본 뒤 완화하면 사전등록이
무의미해진다. 대신 **이 조건이 arm D 에서 무엇을 재는지를 기술한다.**
`benchmark.evaluate_adoption_gates`의 산출에 seed 잡음 하한을 병기하는 것은 향후 과제이며,
그 병기가 판정을 바꾸지는 않는다.

**임계 자체가 틀렸다고 말하지 않는다.** 0.20은 "마스킹해도 군집 구조가 상당히 남아야 한다"는
요구이며 그 자체로는 합당하다. 문제는 **arm D 의 군집이 마스킹과 무관하게 재현되지 않는다는
것**이고, 그렇다면 요구가 겨냥한 성질(마스킹 강건성)을 이 arm 에서 측정할 수 없다. 임계가
아니라 **측정 가능성**의 문제다.

**공정 프로브는 이 문제를 겪지 않는다.** `fair_probe`는 `n_encoder_seeds = 5`로 적합하고
`compare_to_baseline`이 (시점, 분할)별로 학습 arm 의 seed 를 평균한다. 즉 프로브는 설계상
seed 를 평균하고 gate 는 그렇지 않다. C0의 D > B 결론이 기하 비식별성과 양립하는 이유는
프로브가 열공간에만 의존하고(회전 불변) 열공간은 부분적으로 재현되기 때문이다(정렬 0.18–0.20).

### 14.1 차원 민감도 대조 (사전 확정)

§2.1의 A 관찰은 12차원 대 16차원 비교이므로 차원 혼입을 배제해야 한다. **adversary와 무관하며
즉시 계산 가능하다.**

```text
절차   D 의 임베딩을 상위 k 주성분으로 절단하고 각 k 에서 induced R² 를 재계산
       k ∈ {4, 8, 12, 16}      # 16 은 절단 없음 = 0.462 재현 확인
판정   k = 12 에서도 R² 가 A(0.007) 근처로 내려가지 않으면
         → 0.007 대 0.462 의 차이는 차원으로 설명되지 않는다 (§2.1 관찰 유지)
       내려가면
         → §2.1 의 (1)·(2) 를 철회하고 차원 효과로 재서술한다
```

**측정 완료 (2026-08-21, seed 0).**

| 절단 rank | induced R² |
|---:|---:|
| 4 | 0.033087 |
| 8 | **0.074411** |
| 12 | 0.256005 |
| 16 (절단 없음) | 0.462393 |

**판정: §2.1 관찰 유지.** arm A의 차원인 12에서도 R² = 0.256이며 A의 0.0073의 **35배**다.
0.007 대 0.462의 차이는 12 대 16 차원으로 설명되지 않는다.

### 14.1.1 그러나 이 측정은 C2에 대한 경고를 함께 남겼다

R²가 차원에 매우 민감하다. **상위 8개 주성분만 남기면 R² = 0.074로 임계 0.25를 통과한다.**

```text
함의   coverage 누출이 후순위 주성분에 집중되어 있다.
       따라서 **차원 축소만으로 (a) 의 R² 조건과 (c) 를 충족할 가능성이 있다.**
       그 경우 §10 의 E8 veto 가 발동하고 C2 의 방법 기여는 소멸한다.
```

이는 §10의 E8이 가설적 위험이 아니라 **정량화된 실질 위험**임을 뜻한다. `latent_dim = 8`은
이미 E8 격자에 포함되어 있다(§10.1).

**주의 — 이 측정이 E8을 대체하지 않는다.** 학습된 16차원 임베딩을 사후 절단하는 것과
`latent_dim = 8`로 **처음부터 학습**하는 것은 다르다. 또한 절단이 retention ARI와 프로브 ΔR²에
어떤 영향을 주는지는 측정하지 않았다. **E8이 (a)+(b)+(c)를 함께 판정한다.** 위 결과는 E8을
반드시 수행해야 하는 근거이며 그 결과의 예측이 아니다.
