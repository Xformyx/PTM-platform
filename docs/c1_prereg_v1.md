## 0. 이 문서가 존재하는 이유

C1은 설계 v2에서 **유일한 단일 실패점**이다(§0.1.1). 그리고 τ는 그것을 판정할 규칙이 정해지기 전에는
측정해도 의미가 없다. τ를 먼저 계산하고 임계를 정하면 어떤 결과가 나와도 C1을 방어할 수 없다.

따라서 이 문서는 **결과를 보기 전에** 다음을 확정한다.

```text
분석 모집단과 계층 정의
τ 의 정확한 수식 (primary / secondary)
E1b 판별력 판정 기준 — C1 신규성의 최소 조건
E3 calibration / held-out 블록 분할
aggregation 규칙과 출력 통계량
seed 와 결정성
각 실험의 반증 조건
```

**불변 규칙.** 이 문서에 없는 지표를 사후에 primary로 승격하지 않는다. 변경은 §11 수정 로그에
사유·일시와 함께 기록하며, held-out 결과 열람 후의 변경은 어떤 경우에도 primary 판정에 쓰지 않는다.

**구현 시 준수.** 이 문서의 모든 임계·수식은 코드에서 이 문서의 절을 인용해야 한다
(`.cursor/rules/research-code-provenance.mdc`). 코드에만 있고 이 문서에 없는 판정 임계는 사전등록
위반이며, 발견 시 해당 판정을 탐색적으로 강등한다. 변경 이력은 `docs/implementation_log.md`에 남긴다.

## 1. 대상 추정기의 실제 형태

사전등록의 정확성을 위해 진단 대상을 코드 기준으로 명시한다.
`ptm_shared/tmm_identifiability.py` 기준.

```text
site i 마다 독립적으로:
    minimize ||A_i a - y_i||_2   subject to  a >= 0
    보고값 = a / sum(a)

y_i ∈ R^T   site i 의 순서화된 조건(시점) 궤적
A_i ∈ R^{T×K_i}   열 = 후보 kinase 별 시간 활성 프로파일
```

`A_i`는 site별로 다르다(후보 집합이 다르다). 따라서 **τ도 site별 양이고, C1의 분석 단위는 site다.**

이미 구현되어 산출되는 provenance (재구현 금지, 재사용):

| 필드 | 의미 |
|---|---|
| `design_rank` | rank(A_i) |
| `design_condition_number` | cond(A_i) |
| `max_column_coherence` | 열 간 최대 \|cosine\| |
| `active_rank`, `active_sigma_min`, `active_condition_number` | 활성집합 부분행렬 |
| `n_active` | 활성 열 수 |
| `n_redundant` | leave-one-out으로 검출 불가한 후보 수 |
| `equal_weight_fallback` | NNLS 해가 전부 0 → 균등 ratio 보고 |
| `structurally_underdetermined` | K_i > rank(A_i) |
| `relative_residual` | 잔차 / \|\|y\|\| |
| `prior_column_fraction`, `top1_from_prior` | prior 유래 열 비율 |

## 2. 동결 전 선행 확인 (미완)

아래 두 항목은 **가정하지 않는다.** 확인 결과를 §11에 기록한 뒤에 이 문서를 동결한다.

### 2.1 섭동 방향 `d`의 구성 가능성

τ는 상류 표현 변화가 만든 `y`의 변화 방향 `d_i`를 필요로 한다. 인코더
(`ptm_shared/representation/encoder.py`)는 입력 행렬의 재구성 `output`을 산출하므로
`d_i = ŷ_i(arm D) − ŷ_i(arm L1)`이 원칙적으로 구성 가능하다.

**확인 완료 (2026-08-21).** 전문은 `c1_alignment_check_2026-08-21.md`. **판정: 조건부 통과.**

```text
일치      두 경로가 같은 물리량을 쓴다 — PTM_Relative_Log2FC
          reconstruction = output[:, 0:n_time] 은 Track 2 궤적의 재구성이며
          열 순서는 multiview.timepoints 와 같다
          → d_i = reconstruction_D[i] − reconstruction_L1[i] 는 R^{n_time} 에서 잘 정의된다

불일치    5지점.  명시적 adapter 없이는 τ 를 계산할 수 없다 (§2.1.1)
```

최악 시나리오(값 공간 자체가 다름)는 발생하지 않았으므로 **이 사전등록은 무효가 아니다.**

### 2.1.1 `TAU_ALIGNMENT_ADAPTER_V1` (필수, 사전 확정)

```text
A1  site key 정규화
    인코더  f"{gene} {position}" 또는 f"{gene} {position}|{form}"   (공백, 원형)
    NNLS    f"{GENE}_{POSITION}"                                    (밑줄, 대문자)
    → gene·position 을 대문자화하고 밑줄로 결합한 정규형으로 양쪽을 사상한다

A2  form → site 집계        ← **확정. `SITE_LEVEL_ENCODER_V1`. §2.1.2**

A3  조건 집합 정합

    NNLS 의 heatmap["conditions"] 에 control 이 있으면 차원이 다르다.
    → NNLS 조건 벡터에서 control 성분을 제거한 뒤 정렬한다. 제거 여부와 개수를 기록한다
```

### 2.1.2 form → site 집계 — **확정 (2026-08-22). `(a) site 수준`**

기본 설정 `key_level="form"`에서 인코더는 form 단위, NNLS는 site 단위이므로 다대일이었다.
**실측이 이 문제를 축소시켰다** (`scripts/measure_c1_strata.py`, 오더 52).

| 수준 | 적격 행 | A1 정규화 후 고유 site | 다중 form site |
|---|---:|---:|---:|
| form | 2,744 | **2,377** | 300 |
| site | 2,377 | **2,377** | 0 |

**두 수준의 site 집합이 동일하다.** 어느 form 하나라도 적격이면 그 site 는 site 수준에서도
적격이고 역도 성립한다. 따라서 집계 규칙은 **모집단을 바꾸지 않고 `d` 구성만 바꾼다.**

```text
확정  A2 = SITE_LEVEL_ENCODER_V1
      τ 산정용 인코더를 key_level="site", minimum_observed_timepoints=3 으로 적합한다.
      A1 정규화 후 NNLS site 와 전단사이므로 **집계 함수가 필요하지 않다.**

근거  (1) 모집단 손실 0 — 고유 site 집합이 form 수준과 같다
      (2) c1_alignment_check §4 의 (b)(c)(d) 가 모두 불요해진다
      (3) C0 공표 프로브 표가 이미 site 수준(2,447)에서 측정되었다 — 이탈이 아니다

폐기  (c) 최다 관측 form 대표. (1) 때문에 얻는 것이 없는데 정보를 버린다
```

**C2 작업(form 수준, 2,744)의 인코더 가중치를 재사용하지 않는다.** 두 장의 표현이 다른 단위임을
논문에서 명시한다.

### 2.1.3 해석 한계 — 결측 처리 비대칭 (필수 명시)

NNLS는 미관측 조건을 **0으로 대입**하고, 인코더 `reconstruction`은 모든 시점에 값을 낸다. 따라서 `d_i`는
NNLS가 단단한 0을 본 자리에 비영 성분을 갖는다.

**τ는 부분적으로 "대입 채움 방향"의 전달성을 잰다.** 이것은 무해한 기술적 세부가 아니다. 영값 대입은
평가 가능한 site의 **10.1%에서 top-1을 뒤집는다**(`tmm_identifiability_diagnosis.md`). 즉 그 방향은
하류 출력을 실제로 바꾼다.

논문 서술에서 τ를 "표현 변화의 전달성"이라고만 쓰지 않고 **"대입 채움을 포함한 표현 변화의 전달성"**으로
쓴다.

### 2.1.4 `d`의 처리 arm 과 baseline — **확정 (2026-08-22, τ 산정 전)**

§2.1은 `d_i = ŷ_i(arm D) − ŷ_i(arm L1)`이라고 썼는데 `ŷ(arm L1)`이 코드에서 무엇인지가 명시되지
않았다. arm L1은 비학습 arm이므로 **재구성을 산출하지 않는다.** 여기서 확정한다.

```text
TAU_BASELINE_V1 = zero_imputed_l1_trajectory
    ŷ_i(arm L1) := y_i  = NNLS 가 실제로 소비하는 영값 대입 궤적
                          (load_timeseries 가 TSV 에서 복원한 PTM_Relative_Log2FC,
                           미관측 조건은 0.0)

TAU_TREATMENT_ARM_V1 = arm D (learned_temporal_representation, Track 2 only)
    ŷ_i(arm D)  := EncoderResult.reconstruction[i]  = output[:, 0:n_time]
    설정          key_level="site", minimum_observed_timepoints=3 (§2.1.2 A2),
                  eligible_subset() 적용, use_protein_context=False, use_track1=False,
                  use_coverage_adversary=False, seed=0, DEFAULT_ENCODER_CONFIG 의 나머지 값

d_i[t] = ŷ_i(arm D)[enc(t)] − y_i[t]     t 가 인코더 시점에 있으면
       = 0                               t 가 control 등으로 인코더에 없으면 (A3)
```

**baseline 을 여기서 고르는 것이 아니다.** §2.1.3이 "NNLS가 단단한 0을 본 자리에 `d_i`가 비영
성분을 갖는다"고 쓴 것은 baseline이 영값 대입된 `y_i` 그 자체일 때만 성립하는 서술이다. 즉
사전등록이 이미 전제한 값이며 §2.1.4는 그것을 코드가 인용할 수 있게 적을 뿐이다.

**arm D 를 쓰는 이유.** 설계 v2 §11은 C0/C2/C3의 primary arm이 temporal-only(D)라고 이미 정한다.
C1이 다른 arm을 쓰면 장 간 비교가 불가능해진다. arm E는 protein·Track 1 가용성 편향이 섞이므로
τ에 표현 변화가 아닌 가용성 성분이 들어간다.

**용어 주의 — `L1`이 두 뜻으로 쓰인다.** §2.1의 `arm L1`은 **표현 층 이름**
(`ptm_vector_data_normalized*.tsv`, site×timepoint 정량 벡터,
`ptm_representation_learning_contract_v1.md` §2)이고, §3.3의 `L1`은 **모집단 수준**
(HIRc-B 확증 universe)이다. 논문에서는 표현 층을 `L1 layer`, 모집단을 `population L1`로 구별해 쓴다.

#### 2.1.4.1 secondary — 관측 성분만의 τ

§2.1.3의 한계를 **선언에서 측정으로** 바꾼다.

```text
d_full  = 위 정의 그대로                                   ← primary
d_obs   = d_full 을 관측 시점에만 남기고 미관측 성분을 0    ← secondary
```

`τ(d_full)`과 `τ(d_obs)`를 함께 보고한다. 차이가 §2.1.3이 경고한 "대입 채움 방향"의 기여분이다.
**분해가 완전하다고 주장하지 않는다** — 두 성분은 직교하지 않으며 활성집합도 공유한다.

#### 2.1.4.2 A6 — form 값 집계 비대칭 (신규 발견, 2026-08-22)

A1–A5 점검에서 놓친 여섯 번째 불일치다. **`d`의 크기에 직접 들어간다.**

```text
NNLS     load_timeseries 는 같은 (site, condition) 의 여러 form 행을 순회하며
         덮어쓴다 → **마지막 행 승리(last-wins)**
인코더   feature_contract 는 같은 (site, condition) 의 표본을 **평균**한다 (np.mean)

귀결     다중 form site 에서 y_i(NNLS) ≠ 인코더 입력값.
         따라서 d = reconstruction − y 에는 **집계 방식 차이 성분**이 섞인다
```

**이 성분을 제거하지 않는다.** primary baseline은 "NNLS가 실제로 소비하는 값"이어야 하고
(§2.1.4), 인코더 입력으로 baseline을 바꾸면 τ가 배포 추정기를 기술하지 않게 된다. 대신
**크기를 측정해 보고**한다.

```text
agg_mismatch(i) = || (y_enc(i) − y_nnls(i)) ⊙ observed_mask(i) ||
보고            = 계층별 분위, 그리고 || d_obs || 에 대한 비율
```

`agg_mismatch`가 `||d_obs||`에 비해 크지 않다면 §2.2의 성분 (3)은 실질적으로 무해하다. 크다면
**τ의 일부는 표현이 아니라 집계 규약의 산물**이며 그 사실을 논문에 쓴다. 어느 쪽인지는 측정 결과로
정하고, 지금 임계를 정하지 않는다 — 이 양은 판정에 쓰이지 않는 기술 통계다.

### 2.2 `PRIMARY_SCORE_INPUTS_LOCKED` 하에서의 반사실 성격 — **확정 (2026-08-22)**

표현은 production 귀속 결과를 바꾸지 않는다(§8.4). 따라서 `d_i`는 실제 production 변화가 아니라
**반사실(counterfactual) 섭동**이다. τ는 "표현을 바꿨을 때 하류가 그것을 볼 수 있었겠는가"를 재며,
"production이 바뀌었다"가 아니다.

**서술 규약을 다음으로 고정한다. 코드 주석·로그·논문 본문에 동일하게 적용한다.**

```text
쓴다      "표현을 arm L1 에서 arm D 로 바꾸는 반사실 섭동이 고정 사전(dictionary)의
          열공간에 보이는 비율"
          "하류가 그 변화를 볼 수 있었을 정도"
          "대입 채움을 포함한 표현 변화의 전달성"          ← §2.1.3 과 함께

쓰지 않는다  "표현 개선이 귀속을 개선한다/개선하지 않는다"   ← 정확도 주장. 측정하지 않았다
            "production 이 τ 만큼 바뀐다"                  ← 반사실이지 배포 변화가 아니다
            "τ 가 낮으므로 표현 학습이 무용하다"            ← 퇴화는 하류 사전의 성질이다
```

**세 성분이 τ 에 섞여 있으며 분리되지 않는다.** (1) 인코더가 만든 실제 궤적 변화,
(2) 디코더가 미관측 시점을 채운 값(§2.1.3), (3) A2 에서 site 수준으로 적합한 결과 form 간
차이가 흡수된 부분. 논문에서 τ 를 (1)만의 함수로 서술하지 않는다.

## 3. 분석 모집단과 계층 (사전 확정)

### 3.1 계층 정의

기존 TMM 진단 실측(`docs/tmm_identifiability_diagnosis.md`, 6 오더 1,310 site)은 대상 추정기가
대부분의 site에서 **퇴화**되어 있음을 보여준다. τ는 계층에 따라 의미가 달라지므로 계층을 먼저 고정한다.

| 계층 | 정의 | τ의 의미 |
|---|---|---|
| **S-DEAD** | `equal_weight_fallback = True` | **τ 무의미.** 추정기 출력이 데이터의 함수가 아니다(균등 ratio 상수). 전달률은 정의상 0이며 기하 때문이 아니라 코드 분기 때문이다 |
| **S-NOFIT** | `relative_residual ≥ 0.999` (S-DEAD 제외 후) | 적합이 아무것도 설명하지 않음. τ 해석 불가 |
| **S-RANK1** | `design_rank = 1` (위 두 계층 제외 후) | τ = `cos²(d_i, a_1)` 단일 코사인. **`cond`이 ∞로 포화되어 방향 무관 지표와의 비교가 무의미** |
| **S-EVAL** | `design_rank ≥ 2` ∧ `cond` 유한 ∧ 위 계층 아님 | **E1b 판별력 검정이 성립하는 유일한 계층** |

### 3.1.1 실측 (2026-08-22) — **세 수준 전부 검정력 미달**

`scripts/measure_c1_strata.py`. 산출물 `data/outputs/_diagnostics/c1_strata_v1/measurement.json`.
계층은 §3.1의 순서대로 **배타적으로** 적용했다(S-DEAD → S-NOFIT → S-RANK1 → 나머지).
**τ는 계산하지 않았다** — §3.2가 요구한 순서를 지켰으므로 이 측정은 primary 자격을 훼손하지 않는다.

| 계층 | L2 = HIRc-B (500) | L3 = 동결 6 오더 pool (1,160) |
|---|---:|---:|
| S-DEAD | 50 (10.00%) | 537 (46.29%) |
| S-NOFIT | 4 (0.80%) | 102 (8.79%) |
| S-RANK1 | 383 (76.60%) | 429 (36.98%) |
| **S-EVAL** | **63 (12.60%)** | **92 (7.93%)** |
| **S-EVAL ∩ adapter** | **58** | **66** |

```text
L1  ≤ 58   (L2 의 부분집합)   < 73   → E3 primary 평가 불가
L2  =  58                      < 73   → E3 primary 평가 불가
L3  =  66                      < 73   → E3 primary 평가 불가
```

**§3.4의 마지막 조항이 발동한다.** 대응은 §3.5에서 정한다.

두 부수 관찰을 함께 기록한다. 논문에서 이 둘을 뒤집어 읽지 않는다.

1. **HIRc-B가 pool보다 건강하다.** S-DEAD 10.0% 대 46.3%, S-EVAL 12.60% 대 7.93%. 즉
   `|S-EVAL|`이 작은 것은 HIRc-B의 결함이 아니라 **절대 site 수가 적기 때문**이다(500 대 1,160).
2. **오더 간 편차가 극단적이다.** S-EVAL 비율이 0.0%(WithoutCu-AmyloidFibril, 86 site 전부 미달)
   에서 33.3%(Microgravity)까지 흩어진다. **pool 요약은 오더별 표 없이 보고하지 않는다.**
3. **L3 의 6 오더는 독립 획득 6건이 아니다** (2026-08-22 추가, **탐색적** — 데이터셋 단위 감사에서
   사후에 드러났다. `integrated_research_design_v2.md` §11.1.2,
   `chapter2_audit_protocol_v1.md` §4.3.2). Microgravity(오더 45)와
   Korea_timecouse_drugrepositioning(오더 33)은 **원자료 mzML 12개가 완전히 동일**하므로 L3 의
   독립 획득은 5건이다. 위 편차의 상단(33.3%)이 그 쌍의 한쪽이므로 **오더별 표를 "데이터셋 간
   편차"라고 이름 붙이지 않는다** — 재처리 성분이 섞여 있다. 이 사실은 §3.4·§6 의 검정력 선언과
   S-EVAL 크기 실측을 바꾸지 않는다(계층 크기는 site 수로 정의되며 오더 수로 정의되지 않는다).
   다만 §10.1.3 의 교훈("클러스터 단위 추론을 쓰면 검정력 사전등록도 클러스터 수로 해야 한다")이
   **오더보다 거친 층이 하나 더 있다**는 뜻으로 확장된다.

adapter 교집합 감쇠는 L2에서 8%(63→58), L3에서 28%(92→66)다. L3의 감쇠가 큰 이유는 `T = 3`인
오더에서 `minimum_observed_timepoints = 3`이 완전 관측만 적격으로 만들기 때문이며, §3.2가
예고한 대로다.

### 3.2 계층 크기는 미지이며, 이것이 E1b의 최대 위험이다

6 오더 실측에서 rank-1이 54.4%, `equal_weight_fallback`이 46.2%다. 두 계층의 중첩 정도를 알 수 없으므로
`S-EVAL` 크기의 가능 범위는 넓다.

```text
|S-EVAL| 상한  = 1310 × (1 − 0.544) ≈ 597
|S-EVAL| 하한  = 두 계층이 서로소이면 ≈ 0
measured identifiable + weakly identifiable = 34 (2.6%)
```

**즉 E1b가 현재 데이터에서 실행 불가능할 수 있다.** 이 가능성을 사후에 발견하면 C1 신규성 논쟁은
영구 미해결로 남는다. 따라서 **계층 크기 측정을 E1b 판정보다 먼저 하고, 크기에 따른 처리를 지금 정한다.**

주의: 위 비율은 **6 오더 모집단**에서 나온 값이고 E1의 1차 대상은 HIRc-B 확증 universe다. 모집단이
다르므로 위 비율은 사전 기대치이며 실제 계층 비율은 측정 대상이다.

### 3.3 모집단 확장 경로 (사전 확정 순서)

`S-EVAL`이 부족할 때의 확장 순서를 **미리** 고정한다. 사후에 모집단을 고르면 선택 편향이 된다.

```text
L1  HIRc-B 확증 universe            ← 1차
L2  HIRc-B 전체 universe (확증 + sensitivity + 탐색)
L3  6 오더 전체 pool (1,310 site)
```

각 수준에서 계층 비율을 모두 보고하며, **판정에 사용한 수준을 명시한다.** L1에서 판정 가능하면 L2/L3는
민감도 분석으로만 쓴다.

### 3.4 검정력 기준 (사전 확정)

`S-EVAL` 크기 `n`에 따른 E1b의 지위를 고정한다. 근거는 Spearman ρ의 Fisher-z 신뢰구간
반폭(SE ≈ 1.06/√(n−3)).

E1b는 더 이상 pass/fail 관문이 아니므로(§6.1) 아래 기준은 **E1b 기술 통계의 정밀도**와 **E3 primary의
평가 가능성**에 적용된다.

| `n` = \|S-EVAL\| | Spearman 95% CI 반폭 | 지위 |
|---|---|---|
| ≥ 195 | ≤ 0.15 | E1b 중복도 추정 정밀. E3 확증 판정 |
| 73 – 194 | 0.15 – 0.25 | E1b는 CI 폭을 명시해 기술. E3는 검정력 부족을 선언하고 효과크기·CI 보고 |
| < 73 | > 0.25 | **E3 primary 평가 불가.** C1은 미평가로 선언 |

`n < 73`이면 §3.3의 다음 수준으로 확장하고, L3에서도 미달이면 **C1의 예측 진단 주장을 철회하거나
새 데이터를 요건으로 선언한다**(§0.1.1 강등 경로). 교차적합(§7.2) 도입으로 전체 `S-EVAL`이 OOF 평가에
참여하므로 초안의 50/50 분할 대비 유효 표본이 2배가 된다.

### 3.5 미달 확정 후의 처리 — **결정 완료 (2026-08-22). (i) + (iii)**

§3.1.1에서 세 수준 전부 `n < 73`이 확정되었다. §3.4가 예고한 두 분기에 실측으로 드러난 세 번째를
더해 아래에 열거한다. **하나를 택해 여기 기록한 뒤에만 다음 단계로 간다.**

| 분기 | 내용 | 지위 | 대가 |
|---|---|---|---|
| **(i) 강등** | E3를 primary에서 내리고 C1을 **특성화 장**으로 확정. E1(τ 측정)·E1b(기술)·E2(사전 조작 반응)만 수행 | 사전등록된 경로(§0.1.1). primary 자격 유지 불필요 | C1은 "예측 도구"가 아니라 "현상 특성화"가 된다 |
| **(ii) 새 데이터 요건 선언** | `n ≥ 73`을 만족하는 코호트를 논문의 **요건**으로 선언하고 C1을 미평가로 남김 | 사전등록된 경로 | 학위 일정 안에 데이터가 없으면 장이 비어 있게 된다 |
| **(iii) 7 오더 pool 탐색적 수행** | L2 ∪ L3 = 124에서 E3를 돌리되 **탐색적으로만** 보고 | **primary 승격 영구 불가.** 결과를 본 뒤 만든 수준이므로 | 심사에서 "왜 이 모집단인가"를 반드시 받는다 |

**(iii)을 (i)·(ii)의 대안으로 쓰지 않는다.** (iii)은 (i)을 택한 뒤의 **추가 탐색**으로만 성립한다.
즉 (i) + (iii)은 가능하고, (iii) 단독은 사전등록 위반이다.

**HIRc-B가 L3에 없는 이유는 데이터 가용성이다.** 사전등록 당시 오더 52에는
`kinase_activity_heatmap`이 없었고, 2026-08-22 확인 시점에는 저장되어 있다(2.3 MB, 전 오더 최대).
이 사정을 알고도 지금 7 오더 pool을 primary 수준으로 선언하지 않는 이유는 **미달을 본 뒤의
변경이기 때문**이며, 데이터 사정이 정당화 사유가 되지 않는다.

#### 3.5.1 확정된 처리 (2026-08-22, τ 산정 전)

```text
선택   (i) 강등  +  (iii) 7 오더 pool 탐색적 수행
확정   2026-08-22.  E1 착수 전이며 τ 값을 아직 보지 않았다
```

| 실험 | 지위 (개정) | 수행 여부 |
|---|---|---|
| E1 (τ 측정) | **기술.** C1의 주 산출물 | 수행 |
| E1b (기하 중복도) | 기술 통계·CI. §3.4에 따라 CI 폭 명시 | 수행 |
| E2 (dictionary 조작 반응) | secondary → **축소 수행.** §8.3 | 부분 수행 |
| E3 (held-out 예측 타당도) | **primary에서 강등. 탐색적** | (iii)로 수행 |
| E3b (합성 개입 양성 대조) | 탐색적 (변경 없음) | 수행 |

**C1의 주장이 다음으로 좁아진다. 이 문장만 논문에 쓴다.**

```text
쓴다      "고정 사전(dictionary)은 대부분의 site 에서 퇴화되어 있고, 상류 표현 변화가
          하류에 보이는 비율 τ 는 그 퇴화 구조와 함께 계층별로 분해된다"
          "τ 의 예측 타당도는 이 코호트에서 확증적으로 평가할 수 없다.
          |S-EVAL| = 58 (L2) / 66 (L3) 로 사전 지정 하한 73 에 미달했다"

쓰지 않는다  "τ 는 하류 민감도를 예측한다"           ← E3 가 primary 가 아니므로 불가
            "τ 가 예측에 실패했다"                  ← 실패가 아니라 **미평가**다. 구별한다
```

**"미평가"와 "실패"의 구별을 심사에서 반드시 유지한다.** `n < 73`은 τ에 대한 증거가 아니라
**증거 부재**다. 이 구별이 무너지면 강등 경로가 은폐된 실패 보고가 된다.

```text
모집단   L2 (HIRc-B 전체, S-EVAL ∩ adapter = 58)  ∪  L3 (동결 6 오더 pool, 66)

지위     탐색적.  primary 승격 영구 금지.  결과를 본 뒤 만든 수준이다
검정     §7 의 절차(유전자 블록 교차적합·순열검정)를 **그대로** 쓴다 —
         탐색적이라는 이유로 절차를 느슨하게 하지 않는다
보고     p-value 와 Cliff's delta 를 내되 **"통과/실패" 라벨을 붙이지 않는다**
금지     이 결과로 C1 성공을 선언하는 것.  §6.6 의 OR 경로 금지가 여기에도 적용된다
```

#### 3.5.3 E2 를 축소 수행하는 이유

E2는 `H`를 **바꿔가며** τ 반응을 보는 실험이고 설계 v2 §11은 dictionary 최소 1버전을 요구한다.
현재 저장소에 **국소 KSA 라이브러리가 없고**(KEA3 API 의존, `core_ab_p2_frozen_contract_v1.md`),
따라서 **KSA 버전 교체 축은 실행 불가**다.

```text
수행 가능   prior-free 축 = prior 유래 열 제거 (E3b 의 I2 와 동일 조작)
실행 불가   KSA 버전 교체 축 = 두 번째 KSA 스냅샷이 없다

귀결       E2 는 "prior 열 의존도에 대한 τ 반응" 한 축만 보고한다.
           §6.6 이 지정한 secondary corroboration 의 역할을 **온전히 수행하지 못한다**.
           그러나 E3 가 이미 primary 에서 내려왔으므로 C1 판정 구조는 영향받지 않는다
```

**이 축소를 "E2 통과"로 서술하지 않는다.** 한 축만 본 것이며 dictionary 조작 일반에 대한
민감도를 보인 것이 아니다.

## 4. τ의 정의 (사전 확정)

### 4.1 수식

site `i`, 설계 `A_i`, 섭동 방향 `d_i ∈ R^T`, `d_i ≠ 0`.

```text
P_col(M) = M 의 열공간으로의 정사영 (수치 rank 기준, §1의 rank 규칙 재사용)

τ_act(i) = || P_col(A_i[:, active_i]) d_i ||² / || d_i ||²      ← primary
τ_col(i) = || P_col(A_i)             d_i ||² / || d_i ||²      ← secondary
```

`active_i` = NNLS 해에서 계수가 양인 열 집합(기존 `n_active` 정의 재사용).

**primary는 `τ_act`다.** NNLS 추정기의 국소 거동은 활성집합 부분행렬이 결정하므로 배포된 추정기를
기술하는 쪽은 `τ_act`다. `τ_col`은 활성집합과 무관한 구조적 상한으로 함께 보고한다.

**선행 연구 고지 (필수).** `τ_col = dᵀ R_data d / dᵀ d`이며 `R_data = A A⁺`는 선형 역문제의 **data
resolution matrix**(Backus–Gilbert 1968; Wiggins 1972; Jackson 1972)다. 즉 `τ_col`은 신규 양이 아니라
확립된 대상의 방향별 Rayleigh 몫이다. `τ_act`의 활성집합 사용만이 NNLS 특유의 증분이다. 이 사실을
논문과 코드 docstring에서 먼저 밝힌다(`integrated_research_design_v2.md` §9.1.1).

`τ_dd` = 데이터 유래 열만으로 구성한 부분행렬에 대한 `τ_act`. prior 열 의존도를 분리하기 위해 보고하되
**primary가 아니다**(데이터 유래 열이 오더당 0–5개에 불과해 계층이 지나치게 작다).

### 4.2 국소성 유효 검사 (필수)

`τ_act`는 활성집합이 `d_i` 하에서 불변이라는 국소 선형화를 전제한다. 이 전제를 검사한다.

```text
active_stable(i) = (y_i 에서의 활성집합) == (y_i + d_i 에서의 활성집합)

active_stable = False 인 site 는
  primary 분석에서 제외하지 않되 별도 계층으로 표시하고 비율을 보고한다.
  비율이 0.30 을 넘으면 τ_act 의 국소 해석을 primary 에서 철회하고
  τ_col 을 primary 로 승격한다.  ← 이 승격 규칙은 지금 확정된 것이며 사후 선택이 아니다
```

### 4.3 경계 규약

```text
|| d_i || <= 1e-12          → τ 미정의. 분석 제외, 개수 보고
n_active = 0                → S-DEAD 로 분류 (equal_weight_fallback 과 일치해야 함. 불일치 시 보고)
rank(A_i) = 0               → 분석 제외
τ 는 [0, 1] 로 clip 하지 않는다.  범위 밖 값은 수치 오류이므로 보고한다
```

단계이며 여기서 C1의 참/거짓이 결정되지 않는다.

## 6. E1b — 기하 중복도 특성화 (판정 관문 아님)

### 6.1 목적을 분리한다 (v0 → v1 변경)

초안은 두 가지를 한 규칙에 합쳤다: **"τ가 `X`로 환원되지 않는가"(구성 타당도 질문)**와 **C1의
성공/실패 판정(확증 결정)**. 외부 검토에서 이 결합이 부적절함이 지적되었고 수용한다.

이유는 비대칭이다.

```text
R2_iso 가 높아도  τ 가 하류 반응을 예측하면  →  운영 진단으로는 유용하다
R2_iso 가 낮아도  τ 가 하류 반응을 예측 못하면 →  C1 의 도구적 가치는 없다
```

즉 C1의 추론 endpoint는 "X와 다른가"가 아니라 **"held-out 하류 민감도를 사전 예측하는가"**다.

> **따라서 E1b를 C1 채택 관문에서 제거한다.** E1b는 기하 중복도(geometry redundancy)를 **기술**하며,
> C1의 primary endpoint는 E3이다(§7). `R2_iso < 0.80`과 `disc ≥ 0.05`를 기각 조건에서 삭제한다.

### 6.2 방향 무관 예측자 집합 (사전 확정, 추가·삭제 금지)

```text
X = { log10(design_condition_number),
      log10(active_condition_number),
      active_sigma_min,
      max_column_coherence,
      design_rank,
      n_redundant }
```

**계층은 `S-EVAL`에 한정한다.** `S-RANK1`에서는 `cond = ∞`로 포화되어 τ와의 비교가 자동으로
"무상관"이 되므로, 전체 모집단에서 계산하면 **중복도가 인위적으로 낮게 보인다.**

### 6.3 primary 모형은 저용량(low-capacity)으로 한다

등위회귀는 단조 계단함수이므로 표본이 작을 때 과적합에 취약하다. 6개 단변량 등위적합을 비음수
최소제곱으로 결합하면 단일 등위회귀보다 용량이 더 커진다. `S-EVAL`이 작을 가능성이 높은 상황
(§3.2, 하한 ≈ 0)에서 이를 primary로 쓰면 **비환원적 τ를 유연한 nuisance 모형이 과적합해 삼켜버리는
방향의 오류**가 발생한다.

| 항목 | 동결 규칙 |
|---|---|
| estimand | `τ_act`와 사전 확정 `X`의 **out-of-fold 순위 연관 및 단순 모형 설명 분산** |
| primary 모형 | 표준화된 `X`에 대한 **ridge 선형 모형.** penalty는 사전 확정 grid `{0.01, 0.1, 1, 10, 100}`에서 **내부** 유전자 블록 CV로 선택 |
| primary 통계량 | OOF `Spearman(τ_act, τ̂_X)`, OOF `R²`, 유전자 블록 bootstrap 95% CI |
| 등위-NNLS 스택 | **탐색적 robustness 분석.** 전체 스택을 외부 training fold 안에서만 적합하고 OOF 예측만 평가 |
| 결정 | **어떤 임계로도 C1을 기각하지 않는다.** 중복도 프로파일과 불확실성을 기술한다 |

단순 ridge 비교자가 "X가 τ를 전혀 설명하지 않음"을 증명하는 도구는 아니다. 목적은 유연한 모형을
이기는 것이 아니라 **τ가 기존 기하 요약과 얼마나 중복되는지 안정적으로 기술**하는 것이다.

### 6.4 재순서화는 절단점 없는 측도로 한다

`disc`(τ 하위 20% ∧ 예측 상위 50%)는 두 절단점에 민감하고 순위 정보 대부분을 버린다. primary에서
제거한다.

```text
primary   = D_inv = 정규화 역위 비율(normalized inversion fraction)
            비교 가능한 쌍 (i<j) 에 대해
            D_inv = #{ (τ_i − τ_j)(τ̂_i − τ̂_j) < 0 } / #{ 비교 가능한 쌍 }
            동점 쌍은 사전 지정 half-credit 처리

redundant = Kendall tau-b (동점 보정)  ← 함께 보고하되 primary 아님
descriptive = 기존 disc 는 상위 신뢰 구간 충돌의 감사 지표로만 유지. 판정에 쓰지 않는다
```

`D_inv`와 `tau_b` 중 **`D_inv`를 primary로 확정한다.** 결과를 보고 바꾸지 않는다.

### 6.5 편향 방지 장치

```text
X 는 사전 확정이며 결과 확인 후 성분을 빼거나 더하지 않는다
ridge grid 는 위 5개 값으로 고정. 내부 CV 는 유전자 블록 단위 (§7.2)
등위-NNLS 는 primary 와 같은 결론인지 확인하는 sensitivity 로만 쓴다
E1b 는 p-value 를 산출하지 않는다.  기술 통계량과 CI 만 보고한다
```

## 6.6 C1의 성공 논리와 다중성 (사전 확정)

"서로 다른 명제를 검정하므로 다중성 보정이 불필요하다"는 논리는 성립하지 않는다. 여러 endpoint 중
**어느 하나의 유의 결과로 C1 성공을 선언하면** familywise 통제가 필요하다. 반대로 성공이 여러
endpoint를 **모두** 요구하는 교집합 규칙이면 별도 alpha 분할이 불필요할 수 있다.

**C1의 정의를 좁게 확정한다.** §9.1.1–9.1.3의 선행 연구 조사 결과 C1은 신규 진단 지표가 아니라
해석·감사 도구다. 따라서 넓은 주장("기하가 출력 민감도를 예측 가능하게 규정한다")을 하지 않고 좁은
주장만 한다.

```text
C1 = "τ_act 는 고정 하류 추정기의 출력 민감도를 사전 예측하는 진단이다"

primary endpoint  = E3 단독
secondary        = E2 (기전적 corroboration)
금지             = E2 또는 E3 중 하나만 통과했을 때 C1 성공 선언 (OR 경로 금지)
```

| 실험 | 역할 | alpha / 해석 |
|---|---|---|
| E1 | exact-`H` 적격성·provenance 타당성 확인 | 결정적. p-value 없음 |
| E1b | 기하 중복도 특성화 | 기술 통계·CI. **C1 판정 아님** |
| E2 | dictionary 개입에 대한 기전적 민감도 | 사전 지정 secondary |
| **E3** | `τ_act`의 held-out 예측 타당도 | **C1 primary.** 방향 사전 지정(양측 검정, high-τ가 크다는 예측) |
| E3b | 진단 민감도 양성 대조 | 탐색적 |

primary가 E3 단독이므로 **alpha 분할은 하지 않는다.** E2·E1b·E3b의 결과는 primary 판정을 바꾸지 않으며,
E3 실패 시 다른 endpoint의 성공으로 C1을 구제하지 않는다.

## 7. E3 — held-out 예측 타당도 (C1 primary)

### 7.1 회피 대상

τ와 하류 변화 `Δẑ`는 같은 `A_i`와 같은 `d_i`에서 나오므로 동일 표본 내 상관은 기계적으로 발생한다.
그 상관은 NNLS 정사영 성질의 재진술이며 근거로 인정하지 않는다(설계 v2 §5.5.1).

### 7.2 유전자 블록 교차적합 (v0의 50/50 분할을 대체)

**블록 단위 = 유전자(단백질).** 같은 단백질의 site들은 후보 집합과 프로파일 열을 공유하므로 site 단위
분할은 누출이다.

초안의 50/50 단일 분할은 `S-EVAL`이 작을 때 표본의 절반을 판정에서 버린다. `S-EVAL` 하한이 ≈ 0인
상황(§3.2)에서 이는 감당할 수 없는 낭비다. 결정적 교차적합으로 대체한다.

```text
C1_GENE_BLOCK_CROSSFIT_V1
  fold 배정        = sha256(정규화 유전자 기호 + "c1-prereg-v1") mod 5
  외부 fold        = 한 유전자 블록은 통째로 held-out 에 유지
  training folds   = 나머지 4 fold 만으로 모형·분위 임계를 적합
  held-out scoring = 모든 site 가 정확히 1회 OOF 예측/계층 라벨을 받는다
  추론 단위        = 유전자 블록 clustered 순열·bootstrap
  저빈도 규칙      = 어떤 fold 의 held-out high 군 또는 low 군이
                     사전 확정 최소 5 블록 미만이면 그 fold 는 non-evaluable
                     → 그 fold 를 제외하고 제외 사실과 개수를 보고한다
                     대체 분할을 탐색하지 않는다  ← 핵심 금지 사항
```

**계층 불균형 시 재배정 규칙은 삭제한다.** 교차적합에서는 모든 블록이 한 번씩 held-out이 되므로
불균형 보정을 위한 재분할이 불필요하고, 재분할 여지를 남기는 것 자체가 자유도다.

dictionary intervention(E2 계열)은 **별도 축**으로 분할한다. 개입 종류를 사전에 열거하고(§8.1) 같은
방식으로 fold를 배정한다.

### 7.3 training fold에서만 정하는 것

```text
tau_low / tau_high 임계  = training fold 분포의 q20 / q80
                           → 이 경계를 held-out site 에 적용한다.  절대값 아님
site → 블록 aggregation 규칙
ridge penalty (§6.3 의 내부 CV)
```

#### 7.3.1 aggregation 규칙과 seed — **확정 (2026-08-22, E3 산정 전)**

§7.3은 "site → 블록 aggregation 규칙을 training fold에서 정한다"고만 썼고 후보를 열거하지 않았다.
후보 없는 "적합 중 선택"은 통제되지 않은 자유도이므로 **하나로 고정한다.**

```text
C1_BLOCK_AGGREGATION_V1 = median
    블록 b 의 τ    = 그 블록에 속한 OOF site 들의 τ 중앙값
    블록 b 의 Δẑ   = 그 블록에 속한 OOF site 들의 Δẑ 중앙값
    대안 탐색 금지 — 평균·최대·최소를 시도하지 않는다

근거  §5.2 가 이미 중앙값을 primary 요약으로 사전 지정했다. 같은 규칙을 쓰면 규칙이 하나다
```

**추론 단위는 블록이다.** 따라서 high/low 군 배정도 **블록 수준 τ**에 training fold의 q20/q80을
적용해 이뤄진다. site 수준 배정 후 블록을 집계하면 한 블록이 두 군에 동시에 속해
clustered 순열이 정의되지 않는다.

```text
seed  순열검정      = 20260820   (§7.4 에서 이미 동결)
      블록 bootstrap = 20260820   (여기서 확정. 같은 값을 쓰는 이유는 재현 시 기억할 상수를
                                   하나로 줄이기 위해서다. 결과를 보고 정한 값이 아니다)
bootstrap 반복       = 10,000     (순열과 동일)
```

### 7.4 판정 (사전 확정)

```text
Δẑ 정의 = || ratio(y_i + d_i) − ratio(y_i) ||_1     (보고 ratio 벡터의 total variation)

모집단  = baseline 에서 정의된 S-EVAL 만 (조건부 estimand, §7.5)

primary = 전체 OOF site 를 합쳐 계산한
          high-τ 군과 low-τ 군의 블록별 median Δẑ 차이
검정    = 유전자 블록 단위 순열검정 10,000회, 양측, seed 20260820
효과크기 = Cliff's delta (블록 단위)
통과    = 순열 p < 0.05  ∧  |Cliff's delta| >= 0.20  ∧  방향이 예측과 일치
          (high-τ 의 Δẑ 가 더 크다)
```

**금지:** held-out 결과를 본 뒤 임계·aggregation·통계량을 다시 고르는 것, 그리고 통과 실패 후 재분할.
실패 시 §0.1.1 강등 경로를 따른다.

### 7.5 S-DEAD의 처리 — 제외가 아니라 estimand 분리

`equal_weight_fallback` site는 출력이 상수이므로 `Δẑ ≡ 0`이 **구조적으로 강제된다.** 조건부
estimand에서 제외하는 것은 옳다. 포함하면 "살아 있는 scorer에서 τ가 출력 변화를 예측하는가"라는 질문에
0의 질량점이 섞여 검정력과 해석이 모두 나빠진다.

**그러나 두 가지 제약을 동결한다.**

첫째, 제외는 **baseline 기준으로 고정**한다. arm별 결과를 본 뒤 각 arm의 S-DEAD를 따로 제거하면
post-treatment selection이 된다.

둘째, S-DEAD를 숨기지 않는다. 아래 네 결과를 **함께** 동결한다.

| 결과 | 모집단 | 역할 |
|---|---|---|
| 조건부 E3 | baseline 기준 S-EVAL만 | τ의 예측 타당도 (primary) |
| 구조적 사망 유병률 | 확증 universe 전체 | 데이터 반응형 귀속이 불가능한 파이프라인 footprint |
| S-DEAD 전이표 | baseline vs 각 개입 arm | 표현·dictionary 변경이 사망 상태를 바꾸는지 감사 |
| 전체 site 0 포함 요약 | 전체 site, 기술 통계만 | 모집단 수준의 운영상 귀결 |

**용어 확정.** 이 site들을 "전달률 0"이라 부르지 않는다. τ가 정의되지 않거나 목적과 다른 양이 되기
때문이다. **`constant-output-by-construction`(구성상 상수 출력)**으로 표기한다.

## 8. E3b — 기전 양성 대조

### 8.1 개입 목록 (사전 확정)

생물학적 truth 없이 진단의 민감도만 검정한다.

```text
I1  duplicate 열 병합            (coherence >= 0.9999 열 군집을 대표열로 축약)
I2  prior 유래 열 제거           (prior_column_fraction 을 0 으로)
I3  합성 rank 증강               (A_i 에 직교 성분을 추가해 rank 를 단계적으로 올림)
I4  합성 rank 감축               (특이값을 절단해 rank 를 단계적으로 내림)
```

### 8.2 판정 (사전 확정)

```text
예측  I3 (rank 증가) → τ_act 증가,  I4 (rank 감축) → τ_act 감소
primary = I3/I4 의 rank 단계와 τ_act 의 site 내 Spearman 상관 (site 단위로 계산 후 집계)
통과   = 부호가 예측과 일치하는 site 비율 >= 0.80  (부호검정, 양측 p < 0.05)
```

**허용 주장:** diagnostic sensitivity proof.
**금지 주장:** individual kinase accuracy proof, 귀속 정확도 개선.

I1/I2는 방향 예측을 확정하지 않는다. prior 열 제거는 후보 가용성 손실과 교락되어 있어(설계 v2의
`Δ_prior` 교락 문제와 동형) 단일 인자가 아니다. 따라서 **I1/I2는 탐색적으로 보고하고 통과 판정에
쓰지 않는다.**

| E3b | rank 조작에 τ가 반응하지 않음 | 진단 민감도 미증명 |
| 전역 | τ가 모든 계층에서 높음 | 전달 실패가 실재하지 않으며 C1의 동기 소멸 |

**C1의 관문은 E3 단독이다.** E1b는 기술이고 E2·E3b는 보강이다. E3 실패를 다른 endpoint의 성공으로
구제하지 않는다(§6.6).

계층별 `τ_act` 분위. `Δẑ`는 §7.4의 total variation.

| S-DEAD | 549 | 0.000 / 0.000 / 0.000 | 0.097 | 0.000 | 0.000 | 0.122 |
| S-NOFIT | 46 | 0.002 / 0.250 / 0.997 | 0.495 | 0.090 | 0.000 | 0.348 |
| S-RANK1 | 691 | 0.004 / 0.180 / 0.672 | 0.321 | 0.248 | 0.000 | 0.305 |
| **S-EVAL** | **124** | **0.066 / 0.386 / 0.930** | **0.989** | 0.455 | 0.213 | **0.460** |

§4.3의 세 일치 확인은 모두 통과했다: S-DEAD 플래그 불일치 0, 활성집합 불일치 0, τ 단위구간
이탈 0, §4.3 경계 규약에 의한 제외 0건.

**§4.2의 승격 규칙이 발동했다.** `S-EVAL`의 활성집합 불안정 비율이 **0.460 > 0.30**이므로
사전등록된 primary는 `τ_act`에서 **`τ_col`로 바뀐다.** 이것은 사후 선택이 아니라 2026-08-20에
동결된 단방향 규칙의 적용이다.

**승격의 대가를 숨기지 않는다.**

```text
τ_col 은 이 코호트에서 포화되어 있다.  S-EVAL p50 = 0.989, 여러 오더에서 정확히 1.0
원인   T = 3–9 이고 후보 kinase 수 K_i 가 대개 T 이상이므로 열이 R^T 를 거의 span 한다
귀결   τ_col 은 site 를 구별하지 못한다.  §4.2 는 τ_act 의 국소 해석이 깨졌을 때
       τ_col 로 후퇴하도록 정했지만, 이 데이터에서 그 후퇴 지점은 **정보가 없는 지표**다
```

즉 **사전등록된 두 τ 중 하나는 국소 전제가 깨지고 다른 하나는 포화된다.** 이것을 C1의 핵심
한계로 보고한다. 사전등록 규칙을 따르면 primary가 무정보 지표가 되고, 정보가 있는 지표(`τ_act`)를
쓰려면 사전등록을 어겨야 한다. **어기지 않는다.** 두 값을 모두 보고하고 이 딜레마를 기술한다.

A6(§2.1.4.2) 집계 불일치는 `||mismatch|| p50 ≈ 1e-16`, `||d_obs||` 대비 `≈ 1e-16`으로
**부동소수점 수준**이다. `load_timeseries`의 last-wins와 인코더의 mean이 실제로 갈리는 site가
없다. §2.2의 성분 (3)은 실질적으로 무해하며, 이것을 근거로 (3)을 논문 서술에서 제외해도 된다.

### 10.1.2 E1b — 기하 중복도 (§6). **판정 아님**

pool `S-EVAL` 124 site, 101 유전자 블록. OOF ridge, 유전자 블록 bootstrap 95% CI.

| τ | OOF Spearman [95% CI] | OOF R² [95% CI] | D_inv (primary) | Kendall tau-b |
|---|---|---|---:|---:|
| `τ_act` | 0.359 [0.205, 0.499] | 0.125 [−0.006, 0.224] | 0.382 | 0.237 |
| `τ_col` | 0.798 [0.722, 0.843] | 0.552 [0.398, 0.670] | 0.206 | 0.585 |

**해석은 §6.3이 허용하는 범위로 제한한다.** `τ_act`는 사전 확정 기하 요약 `X`로 OOF R² 0.125밖에
설명되지 않으므로 **증분 정보가 있다.** `τ_col`은 0.552로 상당히 중복된다. 이것은 §9.1.1의 선행
연구 고지와 정합한다 — `τ_col`은 data resolution matrix의 방향별 Rayleigh 몫이므로 기존 기하
요약과 겹치는 것이 당연하다.

**§4.2 승격의 두 번째 대가가 여기서 드러난다.** 승격은 primary를 **더 중복된 지표**로 옮긴다.
`τ_act` R² 0.125 → `τ_col` R² 0.552.

**금지.** `τ_act`의 낮은 R²를 "τ는 신규 정보다"의 증명으로 쓰지 않는다(§6.3 마지막 문단).
단순 ridge 비교자를 이긴 것이며 유연한 모형에 대한 비환원성은 검정하지 않았다.

### 10.1.3 E3 — **탐색적 수행조차 평가 불가** (§7)

§7.2의 저빈도 규칙이 **5 fold 전부에서 발동했다.**

| fold | held-out 블록 | low 군 | high 군 | 판정 |
|---:|---:|---:|---:|---|
| 0 | 32 | 4 | 4 | non-evaluable |
| 1 | 18 | 1 | 6 | non-evaluable |
| 2 | 18 | 7 | 2 | non-evaluable |
| 3 | 13 | 5 | 4 | non-evaluable |
| 4 | 20 | 2 | 5 | non-evaluable |

101 블록을 5 fold로 나누면 held-out이 fold당 13–32 블록이고, q20/q80 경계는 각 군에 그 20%인
**2–7 블록**만 남긴다. 사전 확정 하한 5를 양쪽에서 동시에 넘기는 fold가 없다.

**§7.2가 대체 분할 탐색을 "핵심 금지 사항"으로 적었으므로 다른 분할을 시도하지 않았다.**
따라서 C1의 예측 타당도는 **primary로도 탐색적으로도 평가되지 않는다.**

```text
확정   E3 = 미평가 (not evaluated).  실패가 아니다
근거   |S-EVAL| = 124 는 site 하한 73 을 넘지만, 블록 하한이 먼저 걸린다.
       §3.4 의 검정력 표는 site 수로 쓰였고 블록 수를 규정하지 않았다 — 그 누락이
       여기서 드러났다.  이 누락 자체를 논문의 방법론 관찰로 보고한다
```

심사에서 반드시 물어올 동일 표본 상관을 **미리 보고하고 스스로 기각한다.** §7.1이 이 값을 근거로
인정하지 않는다(같은 `A_i`·같은 `d_i`에서 나오는 NNLS 정사영 성질의 재진술).

```text
Spearman(τ_act, Δẑ)  site −0.089   블록 −0.198
Spearman(τ_col, Δẑ)  site  0.072   블록 −0.012
```

**이 값들이 0 근처라는 사실을 "τ는 예측력이 없다"로 쓰지 않는다.** held-out이 아니고 §7.1이
기각한 양이므로 어느 방향으로도 증거가 아니다. 보고하는 이유는 은폐하지 않기 위해서다.

### 10.1.4 E2 (축소) · E3b (§8)

`S-EVAL` 124 site. **E3b는 사전등록 기준을 충족했다(탐색적 지위는 유지).**

| 개입 | 결과 | 판정 |
|---|---|---|
| I3 rank 증강 | 부호 일치 **53/53 = 1.000**, 부호검정 p ≈ 2.2e-16 | 기준 충족 (≥0.80, p<0.05) |
| I4 rank 감축 | 부호 일치 **113/124 = 0.911**, p ≈ 1.3e-15 | 기준 충족 |
| I1 중복 병합 | Δτ_act p10/p50/p90 = −0.0002 / 0.000 / +0.00005 (61 site에서 병합 발생) | 탐색적. 변화 없음 |
| I2 prior 제거 (= E2 축소) | Δτ_act p10/p50 = −0.324 / −0.038. 평가 57 site | 탐색적 |

**E3b의 의미는 diagnostic sensitivity proof 하나다.** τ는 설계 rank를 올리면 오르고 내리면
내린다. 이것은 τ가 기하에 반응함을 보이며 **귀속이 옳아졌다는 뜻이 아니다**(§8.2 금지 주장).
I3에서 71 site가 "단계 부족"으로 제외됐다 — `rank = T`여서 증강 여지가 없는 site들이며,
그 자체가 설계가 이미 포화되어 있다는 §10.1.1의 τ_col 포화와 같은 사실의 다른 표현이다.

I1이 τ를 바꾸지 않는 것은 예상대로다. 중복 열은 열공간을 넓히지 않으므로 정사영이 불변이다.
**이것은 감사 통과 신호이며 발견이 아니다** — 코드가 τ를 열공간의 함수로 올바르게 계산하고 있음을
확인한다.

**I2에서 새로 드러난 사실.** `S-EVAL` 124 site 중 **49 site는 prior 열을 제거하면 열이 하나도
남지 않는다.** 18 site는 애초에 prior 열이 없고, 실제로 τ를 비교할 수 있는 것은 57 site뿐이다.
즉 **평가 가능 계층에서도 설계행렬의 다수가 prior 유래**이며, 이는 설계 v2의 BLOCKER-E를
`S-EVAL`에 한정해 재확인한 것이다. `Δτ_act p50 = −0.038`은 작지만 p10 = −0.324로 꼬리가 두껍다.

**"E2 통과"라고 쓰지 않는다.** KSA 버전 교체 축이 실행 불가이므로(§3.5.3) dictionary 조작 일반에
대한 민감도를 보인 것이 아니다.
